# 动效规范（新野兽派四法则）

日期：2026-09-02 ｜ 适用范围：**全站交互反馈**（按钮、卡片、chip、tab、面板出现）
依据：stylekit.top/styles/neo-brutalist 的四条命名法则 + 本站既有语汇（印章、贴纸旋转、硬阴影）
落地：`frontend/src/style.css` 末尾「新野兽派动效令牌」层

---

## 1. 四条法则与本站取值

| 法则 | 要求 | 本站实现 |
|---|---|---|
**01 Physical Crushing** | 按下时位移 **等于阴影偏移**且阴影清零 —— 物体被压进表面 | `.btn:active { translate(3px,3px); shadow:none }`（阴影 3px）；`.tag-chip:active`、`.tab:active` 补齐 3px；卡片类 4px |
**02 Brutal Snap** | 背景**硬切**，**禁止 opacity 淡入**、禁止渐变 | 面板出现改**盖章落位**（见 §2），不再用淡入 |
**03 Zero Rounding Easing** | 一律 **150ms + ease-out**，禁止弹性回弹（no spring overshoot / elastic settling） | 令牌 `--b-dur:150ms`、`--b-ease: cubic-bezier(0,0,0.2,1)`；全站 50/52 处过渡已归一 |
**04 Heavy Focus** | hover 时阴影**变大且换彩色**，背景硬切 | `--b-shadow-hot: 8px 8px 0 0 var(--red)`；`.ac-card:hover`、`.dv-next-card:hover`、`.card-hover`（本站原有 12px 红） |

```css
:root {
  --b-dur: 150ms;
  --b-ease: cubic-bezier(0, 0, 0.2, 1);
  --b-shadow: 4px 4px 0 0 var(--ink);
  --b-shadow-lg: 8px 8px 0 0 var(--ink);
  --b-shadow-hot: 8px 8px 0 0 var(--red);
}
```

## 2. 面板出现＝盖章，不是淡入

```css
@keyframes b-stamp-in {
  0%   { transform: scale(1.06) rotate(-1.2deg); }
  60%  { transform: scale(0.985) rotate(0.4deg); }
  100% { transform: scale(1) rotate(0deg); }
}
```
- **只有 transform，没有 opacity**（法则 02）
- 从大压到位、硬停 —— 与参考站 `brutal-stamp` 同形，也与本站"印章/贴纸"语汇一致
- `tab-pop` 原来是 `0.94 → 1.04 → 1` 的**回弹**（违反法则 03），已改成同一形状

## 3. 例外（有意保留）

| 例外 | 理由 |
|---|---|
装饰性动画（跑马灯、呼吸）保留 500ms 级时长 | 它们不是"交互反馈"，压成 150ms 会失去节奏 |
`.btn` 的 hover 是"轻压 2px"而非"阴影变大" | 本站按钮**静止态带 `rotate(±1deg)` 贴纸感**，hover 压平旋转已是明确反馈；改成阴影变大要全站重做，收益不抵风险。**一致性优先于教条** |
进度条/图表宽度用 150ms | 数据变化不该比用户操作更慢 |
`prefers-reduced-motion` | 全部动效退回无（位移也取消），不是"变慢" |

## 4. 为什么之前"看起来诡异"

不是某个动画做错了，是**同一类反馈有 8 种时长**（80/120/140/150/160/180/200/220/260ms）且缓动混用 `ease`（两端都慢，显得拖）与一个带 overshoot 的贝塞尔。人眼对"节奏不统一"比对"某个动画不好看"敏感得多 —— 归一到 150ms ease-out 后，全站手感立刻一致。

## 5. 新增交互时的规则

1. 用 `var(--b-dur) var(--b-ease)`，不要写字面时长/`ease`
2. 元素有硬阴影 → 必须写 `:active { translate(Npx,Npx); box-shadow:none }`，**N = 阴影偏移**
3. 卡片 hover 要"更重"（阴影变大 + 换彩色），不要只做位移
4. 出现/消失**不要用 opacity 淡入**，用盖章或硬切
5. 新动效一律包 `@media (prefers-reduced-motion: reduce)`
