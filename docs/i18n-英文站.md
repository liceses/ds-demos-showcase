# i18n 英文站（UI 双语：zh/en）

> 2026-08-30 P1 上线。目标：astra 外网热度引流——英文访客可完整浏览访客链路（首页/作品库/详情入口/排行榜/标签）。
> **零依赖自研**（`src/i18n/`，~90 行），与 funMode 同一套响应式机制。

## 一、边界（先读这个）

| 层 | 处理 |
|---|---|
| UI 固定文案 | zh/en 双语 |
| UGC（Demo 标题/简介、论坛帖、评论、prompt） | **永不翻译** |
| 标签值（ds-unknown、我的世界…） | 不翻（显示层整活归 funMode 管，见 `整活模式.md`） |
| 标签键 label（模型/类型…） | 前端 `KEY_LABELS` 字典映射（model→Model…），未知 key 回落后端中文 label |
| 管理后台 | **不做 EN**（操作者是中文团队；与 funMode 的 /admin 豁免一致） |
| 后端错误信息（detail 中文） | P1 未映射；后续可按错误 `code`（`http_401` 等）在前端映射高频项 |

## 二、覆盖式约定（本仓库的 i18n 写法，与 vue-i18n 常规不同）

```ts
// 模板里：中文原文内联作为回落源，key 只用于 en.ts 覆盖
{{ t('home.featured', '精选作品') }}
{{ t('demos.allLoaded', '已加载全部 {n} 个 Demo', { n: total }) }}   // {n} 插值
{{ tArr('taglines', zhPool) }}        // 数组文案（打字机梗池），en 缺失回落中文
keyLabel('model', '模型')              // 键 label：en → Model，zh → 模型
modeLabel('fixed')                     // 固定值 / Fixed
vendorLabel('阿里')                     // Alibaba（专有名词原样）
```

- **zh 不进字典**：中文原文就是模板第二参数，改中文 = 改模板一处；en.ts 是唯一翻译产物。
- **缺 key 安全**：en.ts 漏写 → 显示中文，绝不显示 key 本身（最坏情况 = 没翻到，不是 bug）。
- 新增文案：模板写 `t('view.key', '中文')` + en.ts 补一条，两步。

## 三、切换机制

```
?lang=en / ?lang=zh   →  当前标签页覆盖（sessionStorage，可分享英文链接，与 ?fun=1 同款）
顶栏 EN/中文 按钮      →  setLang()：写 localStorage('dsh_lang') + 清除标签页覆盖（显式选择最优先）
首次访问              →  navigator.language 探测：en* → en，其余 → zh（站点根本盘中文）
生效                  →  lang ref 响应式：全站（含 keepAlive 缓存页）即时重渲染；
                         <html lang> 同步（watchEffect）
```

## 四、与 funMode 的联动（整蛊闭环）

- **fun ON → 语言预设 EN**（`applyServerFunMode` 内实现）：保存之前语言，fun OFF 时恢复；
  fun 期间手动切了语言则以手动为准（恢复条件：lang 仍是 'en' 才回退）。
- **品牌四组合**（`titleBase`）：fun+zh「astra 灰测作品收集」/ fun+en "astra canary works collection" /
  zh「AI 全民制作人」/ en "AI Demo Makers"。浏览器标题、页脚、顶栏（fun 时）随动。

## 六、排障

| 现象 | 原因/处理 |
|---|---|
| EN 下某处显示中文 | en.ts 缺该 key（安全回落）——补一条即可，非 bug |
| 手动切了语言刷新后变回 | 顶栏切换会写 localStorage；只有 `?lang=` 标签页覆盖优先级更高（setLang 已自动清它） |
| fun 开了还是中文 | fun 预设只在 fun 从关→开时触发；已开状态下手动 `setLang('en')` 或带 `?lang=en` |
| 英文文案风格问题 | en.ts 全部人工/AI 打磨过的态度化短句，改字典即可，不涉模板 |
