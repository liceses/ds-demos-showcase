### 1.2 「傻子也能用溜，艺术家挑不出刺」的双面解释

- 对傻子：**复杂度转给系统**（Tesler 守恒）——OR/AND 语义显性化、空态四出口、默认值/建议包/快捷档、每一步有且只有一个主动作。
- 对艺术家：**一致性即品味**——三层 token 让每个色值有出处、每条动效有令牌、每个断点有名字；「保留灵魂 + 收口硬规范」消灭风格漂移而非消灭个性。

## 2. 诊断摘要（详细见 01/02）

**四大失守 + 一个战略事实**：

1. **样式系统失守**：`style.css` 6304 行（占 src 25%）、17 天 13→108KB 增长曲线、80 个追加式分区、451 处内联样式、两套断点并存、4 个二级 token 未定义却被引用 70+ 处（次级灰字/深纸底/等宽字在静默失效）。
2. **信息架构失守**：25 视图对 5+1 导航项；论坛是独立壳但主导航无入口；admin 18 面板单 chunk 132KB；README 功能底账偏差约 40%。
3. **组件层失守**：48 组件仅 14 个真复用、30 个单点、4 个死组件；`UploadView` 1386 行/10 类职责；`.section-head` 组件死了但 class 被手抄 35 处。
4. **工程失守**：无测试/lint/CI；vite 零 build 段；mock 与 realApi 125×2 双实现；worker 1021 行死码 + **wrangler.toml 明文泄露 OSS AccessKey ID（LTAI5t7…，需立即轮换并清除）**。
5. **战略事实**：真悬崖顺序 = 治理人工（已到临界）→ 搜索质量 → SQLite 写并发 → 无 LLM 不可运营；展示侧暂无悬崖 → **重设计投入必须同时服务「治理侧提效」**，而非只翻新展示层。

**必须继承的资产**（重设计不得丢弃）：`api/types.ts`（62 引用契约层）、14 个真共享原语、adminQueues 单一口径、funMode/i18n 持久化范式、astra 双皮分叉、nginx/Docker 拓扑、全库中文决策注释。

**必须继承的红线**（02 §6.1 全盘）：不做综合排名/能力雷达/SOTA 结论；LLM 只建议不决定；候选不外泄；合并必经 dry_run；契约只增不改；「假动作比没动作更坏」；`prefers-reduced-motion` 全动效退场。

## 4. 设计原则（第 1 层）

### 4.1 认知/信息科学公理（03 §1.1 精选）

米勒 7±2（导航 ≤6+CTA、分面组 ≤7）· 希克（每屏一个主动作）· 菲茨（44px 底线、上传 FAB 居拇指热区）· 渐进披露（详情页 `<details>` 证据区、分面抽屉）· 识别优于回忆（chips 可点不靠记）· 信息气味（入口带实时数字）· 峰终定律（上传成功态/评分回应）· 雅各布（URL 全保留、渐进迁移不强拆心智）· WCAG 1.4.1（状态=色+形/文双通道）。

### 4.2 参考站交互物理（用户指定参考，已考古原文）

- **Physical Crushing**：active 位移量 = 阴影偏移，完全压平；hover 是增影抬起不是压平（**现网 hover 物理相反，统一为参考物理**）。
- **Brutal Snap**：hover 换色硬切 0ms，禁渐变/淡出；位移与阴影统一 150ms ease-out。
- **两枚署名动效吸收**：`brutal-stamp` 盖章强档（350ms easeOutExpo，路由级登场专用）+ `brutal-march` 蚂蚁线（进行中语汇，替换 opacity 呼吸）。
- **移动端 50% 缩放律**：边框 2→4px、阴影 3/5→4/8px，一条缩放律替代两套断点。
- 节制红线：同屏至多一个 march；stamp-hard 仅路由级一屏一次；列表循环内禁用编排动效。

### 4.3 信息科学纪律

标签=键值分面（Ranganathan）：面内 OR、面间 AND 必须在 UI 可见；**Model 享有高于普通标签的 UI 权重**（v2 §6.4）；新知识对象一律从探索下钻，顶栏不扩容（红线）。

## 5. 信息架构要点（第 3 层，全案见 03）

### 5.1 空间模型与导航

- **五空间**：逛（首页/作品库/探索/排行榜）→ 看（详情三兄弟，无导航位）→ 玩（论坛/通知/个人空间）→ 传（上传）→ 管（工作台独立域）+ 账户横切；任何页面到任何空间 ≤2 跳。
- **主导航定稿**：首页/作品库/探索/排行榜/**论坛（新入）**/关于 共 6 信息项 + **「上传 Demo」升为主 CTA 按钮**；admin 移入用户菜单（带待办徽章，URL 不变）；新增顶栏搜索与主题切换器。
- 论坛双皮壳保留（只解决「从外面找不到论坛」）；admin 独立壳保留。
- URL 纪律：**现有 URL 全保留**；新增仅为实体子资源（`/user/:u/followers`）与 query 状态（`/leaderboard?tab=users&range=week`）。

### 5.2 六实体骨架

Model/Task 一等面（已有页保留增强）；Prompt = 作品库「提示词模式」透镜（不设 /prompts）；Run = 详情页证据叙事（不建实体，红线维持）；Rating = 横切层（详情浮标 + 双榜 + 收缩分）。浏览闭环保证：任何 Demo 页必有「署名→模型」「同题→题目」「同句→提示词对比」三条下钻。

### 5.3 关键页动作（全案见 03 §3-9）

- **首页枢纽化**：入口三卡→胶囊行；公告贴纸墙升侧栏（移动横向卡）；入口带实时数字；精选换池口径透明化。
- **作品库**：分面抽屉（桌面可钉/移动 bottom-sheet）+ 已选 chips 摘要条 + OR/AND 显性化 + 空态四出口 + 「随机」改名「随便看看」。
- **Demo 详情**：v2 阅读序骨架不动，修补预览三态（加载蚂蚁线/错误+重试+外部打开/点击播放）、评分样本档、移动底部动作条。
- **上传**：四步向导保留（拒绝单页）+ 组件拆分（5 composable+4 子组件边界已给）+「没有这道题？提议新题」候选出口（M3）+ 峰终成功态。
- **工作台**：概览台改待办驱动（批量消化 + 灰测池 90 天揭晓提醒常驻卡）+ 18 面板深链 `?tab=x&filter=y` + 用户管理分页 + 公告互链输入。
- **移动端**：底部 TabBar（首页/作品/上传 FAB/社区/我的）为移动新基线，旧 541 行适配区逐步替换。

## 6. 设计系统与架构要点（全案见 04）

### 6.1 视觉规范 v3.1 = 保留灵魂 + 5 项收口

- **灵魂不动**：五强调色（#ff6b6b/#4ecdc4/#ffe66d/#95e1d3/#f38181）、纯黑边框硬偏移阴影、rounded-none、贴纸/印章旋转（仅装饰小元素）、盖章语汇、Inter+JetBrains Mono、论坛牛皮纸作用域子主题。
- **收口（R1~R8）**：R1 边框响应式（2→4px）· R2 阴影三档缩放律（小 2/4、中 4/8、大 6/12，crush 位移与阴影共用单源变量）· R3 断 token 补齐（--ink-soft #555 / --paper-deep #f2eee6 / --font-mono 别名 / --shadow-black-sm 硬影）· R4 hex 收编（实测 96 处/34 色，第一批 62 处）· R5 动效双速制（150ms 硬切 + 350ms easeOutExpo 编排档；**v3.3 用户加量**：页面转场=旧页 0ms 硬切消失+新页 stamp-lite 登场 250ms、微交互词汇表（chips pop/评分盖章/铃铛 shake/count-up/Tab march/复制 stamp）、首屏轻量交错入场 ≤8 项 stagger ≤30ms（覆盖旧「列表不逐项入场」红线，加载更多仍仅轻淡入）、同屏非用户触发并发运动 ≤3、opacity 白名单仅限编排类）· **R6 hover 物理统一**（hover=增影+抬起、active=瞬间压平；现网 .btn 压平式 hover 与 v2 规范例外条款作废，全站归一）· **R7 颜色 0ms 硬切**（transition 白名单只许 transform/box-shadow）· **R8 静止零倾斜**（用户新拍板：主要承载文字的卡片/元素静止态旋转=0°；倾斜仅存于 ①装饰小元素常驻（印章/贴纸/徽章）②stamp 入场归零轨迹 ③按压瞬时微倾 ±1°·150ms 归位；hover 不倾斜。tilt 三令牌：`--tilt-rest:0deg` / `--tilt-press:-1deg` / `--tilt-deco:-1.5deg`（装饰白名单专用，归位走 --b-dur）；实测 style.css 50 处 rotate() → **清零组 ≈12 选择器**（.btn 族/卡片族/导航态/tag 面板等）、**保留组 ≈14 处**（stamp/badge/ann-pin/forum-peek）；机器化结论：stylelint 粗防 + CDP 反解 rotate 为权威断言门；整活模式彩蛋层已采纳（fun_mode 下 odd/even 卡片 ±--tilt-deco，P3 可选可砍，≈10 行））。
- **stylepkg 裁决**：不引入 Tailwind；SKILL.md 降为「Tailwind class ↔ 本站 token」翻译词典；禁止项翻译成 stylelint 机器规则——文档与校验从此一份口径。

### 6.2 多主题（用户硬需求）——三层 token，主题=语义层换装

- 三层：L1 原始（原子值，不随主题）× L2 语义（--ink/--paper/…，**名字零改名**，存量引用是资产）× L3 组件（只准引用 L2，stylelint 守护）。
- 主题切换只发生在 L2：`html[data-theme]` 换表，组件零改动。**首发主题集（03/04 终版对齐）：纸白（paper，现网基因）/ 墨黑（ink，参考色板并入，含低饱和变体规则）+ 跟随系统默认**；hc 高对比降 P2；独立 acid 主题取消（并入墨黑）。**墨黑硬阴影决断**：`--shadow-color` = 暖白 #f5f2ea（对卡底 15.07:1；「更深底色」黑上黑 <2:1 已否决），荧光影仅留给 hover 档 `--accent-hot`。
- **dark 关键设计**：`--shadow-c: var(--ink)` → 结构色反相后硬阴影自动翻白影（neo-brutalist dark 正统做法），强调色不翻转；前提是 R4 hex 收编（89 处散落 hex 是 dark 的硬义务）。
- 切换机制：`theme.ts`（同构 funMode 范式：localStorage + sessionStorage 预览 + `?theme=` URL 预览）+ index.html 3 行防闪 + 250ms 硬切闸（防全页渐变违反法则 02）+ color-scheme 同步 + KeepAlive 零处理。
- 每主题 WCAG 对比矩阵实算进 CI（23 组配对，相对亮度公式）：粉底+黑字 5.48 ✓ / 粉底+白字 3.83 ✗（与参考站数据吻合）；**新实锤：现网 `.btn-primary` 红底白字 = 2.78:1 不达 AA → P2 改黑字（7.57 ✓）**，并上升为「红粉底一律黑字」复查规则。
- **别名桥退役纪律**：语义层新名（--paper-2/--ink-faint/--accent-* 等）与存量名（--ink/--paper/…）之间走「遗留别名桥」，**68+ 处存量引用零改名**；别名桥退役时点 = P3 末，勿提前删除（04 §3.1）。
- **口径单源**：「红粉底一律黑字」等用色规则与 04 §3.7 对比度验收同源实现，避免 03/04 双口径漂移。

### 6.3 CSS 工程与构建

- 6304 行按 80 分区**保序机械拆迁**到 `src/styles/` 六层（tokens/base/components/layouts/pages/utilities）；搬移≠改写；新组件一律 scoped；451 内联三分法（数据驱动 11 处保留，目标 ≤100 不追零）。
- 断点收敛 480/720/1024/1280 四档（760→720、900→1024，共 4 处回归面）；stylelint 白名单只许收敛不许新增。
- vite build 段最小配置；AdminView 17 section 惰性组件表（132KB→壳 ~25KB）；en.ts 动态化（中文用户 -60KB）；UploadView 拆分地图（5 composable + 4 子组件，随迭代执行）。
- 行为契约修补：心跳加 visibility 判定、toast 上限 5、401 例外注释化。
- 工程化最小集：stylelint → vitest 冒烟（token 完备性 + 三主题对比度断言 + 路由快照）→ CI 三步门（typecheck+lint:css+build）。

## 9. 风险清单（两文档合并精选）

1. **安全（最高优先，方案外但必须提）**：`wrangler.toml` L20 明文 OSS AccessKey ID——**建议立即在阿里云控制台轮换该密钥并从仓库历史清除**（本方案步 0.5）。
2. dark 盲区：hex 收编第一批完成前 dark 不出预览（04 风险 2，硬门槛）。
3. 机械拆迁级联风险：保序搬移 + 5 页 × 2 视口 CDP 截图比对（04 风险 1）。
4. 边框响应式化引发整站密度重排：逐组件灰度，页面级最后（04 风险 3）。
5. users/leaderboard range 未知：不支持则禁用窗口（不做假开关）（03 R3）。
6. TabBar 与旧 541 行适配区并存冲突：TabBar 为新基线，旧区按页替换（03 R8）。
7. 出题候选队列增量：批量消化（M2）先行，出题出口放 M3（03 R6）。
8. stylelint 首跑洪水：先 warning 存量、收编达标后转 error（04 风险 8）。
9. **hover 物理翻转改变老用户手感**：属规范级变更（v2 动效规范 §3 例外条款作废）——对策：动效规范文档升版记录裁决；分批灰度（先原语族后页面级）。
