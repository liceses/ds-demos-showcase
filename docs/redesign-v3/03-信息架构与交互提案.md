### 1.2 信息科学：分面分类法

本站标签是「键值对分面」（model:* / type:* / category:* / game:* / 技术键…），天然对应 Ranganathan 分面分类。IA 纪律：

1. **键=面（facet），值=面内取值**；面内 OR、面间 AND 的语义必须在 UI 上可见（§4.2）。
2. **Model 不是普通分面**（v2理想设想 §6.4）：它是用户最关心的元数据，UI 权重必须高于其他键（卡片署名行、筛选器置顶组、详情页署名 chips）。
3. **新知识对象不占导航位**（继承红线）：新实体一律从「探索」或实体详情下钻，顶栏不扩容。

### 1.3 继承的红线（02 §6.1 全盘继承，本文不再论证）

不做综合排名/能力雷达/SOTA 结论；LLM 只建议不决定；候选不外泄；合并必经 dry_run；slug 必须 ASCII；契约只增不改；「假动作比没动作更坏」（不给没有数据支撑的按钮）；`prefers-reduced-motion` 全动效退场。

### 1.4 视觉与动效基线（保留并完善，非本文展开项）

- 参考站四法则（Physical Crushing / Brutal Snap / Zero Rounding Easing 150ms / Heavy Focus）的**时长与缓动令牌**本站已归一（`--b-dur/--b-ease`，52 处过渡 50 处走令牌）——保留；但 **hover 物理按用户拍板的参考物理反转**（见下条）。
- ⚠️ **hover 物理反转（重设计变更点，不是保留项）**：参考物理 = hover **阴影增大并向左上抬起**（如 6→10px + translate 左上）、**active 才压平**（位移=阴影偏移且阴影清零）；本站现状（`动效规范.md` §3 例外条款）是「hover 轻压 2px/阴影归零」——物理相反。重设计统一为参考物理，现网「轻压」例外条款随本次废止；`.btn/.tag-chip/.tab/.card` 全部按新物理归一（本文定语义，t4 定令牌值）。
- **阴影三档缩放律**（参考提炼 §一）：小 2/4、中 4/8、大 6/12（mobile/md）——全站硬阴影只用这三档 token，禁止自造档位、禁止 blur。
- 参考站两个署名动效补入本站词汇表：
  - `brutal-march`（蚂蚁线：`repeating-linear-gradient` 背景位移动画，0.6s linear infinite）→ 用于**进行中**状态（上传进度、处理中按钮边框），替代模糊 spinner 的一部分场景；
  - `brutal-stamp`（盖章入场：scale 1.4/rotate -6° → 0.96/1° → 1/0°，0.35s `cubic-bezier(0.16,1,0.3,1)` easeOutExpo 系）→ 本站已有 `b-stamp-in`（1.06→0.985→1），**幅度取本站值（更克制）、曲线统一 easeOutExpo 系**，用于弹层/面板/状态变化出现。
- 参考站规范页关键落地点（已存档 ref/style-zh.txt，供 t4 直接引用）：移动端数值≈桌面 50%（border 2/4、shadow 4/8、p-4/8）；44px 触达；暗色=语义 token 不做反相；组件状态覆盖清单（悬停/键盘焦点/禁用/加载/空/错误/成功）；WCAG 对比数据（#ff006e 上白字 3.83:1 **不达 AA 正文**→CTA 文字用黑字或仅大字号；#ccff00+黑 17.87:1、#00d9ff+黑 12.37:1、#ff9500+黑 9.55:1 均优）。

## 2. 总体空间模型与导航

### 2.1 五空间模型：逛 → 看 → 玩 → 传 → 管

```
 逛（发现）        看（检视）           玩（参与）          传（创作）        管（运营）
┌──────────┐   ┌──────────────┐   ┌──────────────┐   ┌────────────┐   ┌────────────┐
│ 首页(枢纽) │──▶│ /demo/:slug  │──▶│ 论坛(+话题/发帖)│   │ /upload     │   │ /admin 工作台│
│ 作品库     │   │ /models/:slug│   │ 通知中心       │   │ 挑战 ?task= │   │  (独立域)    │
│ 探索       │   │ /tasks/:slug │   │ 评分(详情页内)  │   │ 出题候选(新) │   └────────────┘
│ 排行榜     │   │ /tag/:k/:v   │   │ 关注(个人页)   │   └────────────┘
└──────────┘   └──────────────┘   └──────────────┘
─────────────────────────────────────────────────────────────────────────────
账户域（横切）：/login /register /settings /notifications /user/:username（个人空间）
```

- **空间之间的主路径**只有三条，其余全部是侧路：逛→看（卡片点击）、看→玩（评分/讨论/关注）、逛→传（CTA/挑战）。任何页面到任何空间 ≤2 跳（[希克]：不制造平行入口）。
- **管是独立域**：独立壳（现 ForumHeader 同理的 AdminShell 思路已存在）、独立导航、入口收进用户菜单。访客永远看不见它的存在（[雷斯托夫]反用：普通用户视野内保持干净）。

### 2.2 六实体 → 站点面映射（IA 骨架）

| v2 实体 | 站点面 | IA 地位 |
|---|---|---|
| **Demo**（做出什么） | /demos 作品库 + /demo/:slug | 门户实体，卡片是全站第一信息单元 |
| **Model**（谁做的） | /models + /models/:slug | 一等实体；UI 权重高于普通标签（v2 §6.4） |
| **Task**（做什么） | /tasks + /tasks/:slug | 一等实体；同题比较的骨架（红线：不升「综合榜」） |
| **Prompt**（怎么要求） | **不是独立页面**：作品库「提示词模式」透镜（§4.4）+ 详情页 `PROMPT=` 对比节 | 浏览透镜与叙事元素；v3 不设 /prompts（候选簇 374 件撑不起一级面） |

## 3. 首页重设计：从「菜单」到「枢纽」

### 3.1 角色定位

现状首页是「入口大厅」：hero + 三张入口卡 + 精选 + 灰测 + 公告沉底。问题：对回访用户，入口卡是重复噪音（[识别]：他们已会导航）；公告沉底=发出去没人看见（运营动作浪费）。

### 3.3 DemoCard（瀑布卡片）信息密度设计

卡片是全站第一信息单元，密度纪律：**四通道各司其职，每通道只带一种语义**（[显著度]）。

| 通道 | 承担语义 | 实现 |
|---|---|---|
| 位置 | 内容本体 | 预览图（或 iframe 海报）占卡顶 |
| 尺寸 | 标题 > 署名 > 元信息 | 字阶固定 3 档，不再自由发挥 |
| 颜色 | 模型署名=品牌强调色边框；分数 stamp=黄底 | 走语义 token（多主题下重验） |
| 形状 | 印章（神作/鬼作）、贴纸（更新过，仅小元素）、灰测虚线边 | 沿用本站印章语汇；**全站静止零倾斜（用户拍板）**：一切主要承载文字的元素静止态 rotation=0°（含现网 `.btn` 的 ±1° 静止旋转，一并归零）；倾斜只存在于三类例外：①装饰常驻（印章/贴纸/徽章/非文字装饰块，±1~2°）②入场瞬时（stamp 落定归零）③按压瞬时（active 微倾，150ms 归位，§12.5）；另 fun 彩蛋层为 P3 可选的静止卡片倾斜唯一合法入口（§12.5 注） |

> **静止零倾斜·依据注记（用户拍板）**：斜排文本增加阅读成本（视线需补偿旋转角）、对眩晕/前庭敏感用户不友好；playful 个性由印章/贴纸/硬阴影/强调色承担，不靠卡片倾斜——与参考站 plain 规范「无旋转」（参考提炼 §三对账）一致。`动效规范.md` §3「按钮静止态 ±1° 贴纸感」例外条款随之废止。

**卡片字段定稿**：预览图 / 标题 / 模型署名 chips（→模型页）/ ★分数+**样本档 n=xx**（02 4.1 指出作品级无样本档会误导）/ 浏览数 / type 类别角标 ≤2 / 更新时间。**不放描述摘录**（卡片是入口不是摘要；描述进详情，保住瀑布流节奏与扫读速度 [负荷]）。

- 「玩一下」入口：卡片右下角 `▶ 就地预览`（复用 PeekDrawer，不整页跳转）——逛→看的最低成本路径。
- 移动端卡片同构：预览 16:9、字段减为 标题/署名/分数（样本档保留，字号降 1 档）。

### 4.2 分面筛选器（核心重构点）

现状：筛选条内联铺开（厂商分组折叠+int 滑条+热门 chips），移动端是长滚动条。问题：筛选 UI 与内容抢同一块版面；分面语义（键内 OR/键间 AND）不可见。

```

```

设计要点（每条标依据）：

1. **筛选是间歇动作，浏览是持续状态**→ 筛选器默认收起为按钮，已选条件永远以 chips 摘要条可见（[披露]+[识别]：条件可读可删，不用记）。
2. **Model 组置顶**且独立视觉（模型=一等实体，v2 §6.4）；厂商子分组折叠保留现状机制。
3. **OR/AND 语义显性化**：组头注一行微文案。现状键内 OR/键间 AND 正确但不可见，用户靠试错学习（[识别]反例）。
4. **数值键给快捷档**（如 rounds: 1-2 / 3-5 / 6+）+ 自定义滑条并存（[守恒]：把「构造范围」的复杂度转给系统）。
5. **热门 chips 保留**在搜索行下（高频条件前置 [帕累托]直觉）。
6. 移动端 bottom-sheet 每次只展开一个组（[米勒]），应用即收起；抽屉头显示「已选 N」。
7. 全部状态同步 URL query（现状已做，保留）——分享/回退不丢条件。

### 4.3 排序与默认

默认「最新」保留；「最热」「随机」保留。新增一个决策：**「随机」重命名为「随便看看」**并移到末位——「随机」在数据产品语境里像统计功能，「随便看看」表达消遣心智（文案即语义）。

### 4.4 提示词模式的定位

现状：`cardMode normal|prompt`（localStorage 持久化，prompt 模式用 PromptDemoCard 且 sort='prompt'）。

IA 定位：**它是创作者/agent 的调研透镜，不是默认形态**。落位与文案：

- 视图切换器保留（mode-rail 轨道），文案改「常规 / 提示词」，徽章 `PROMPT` 保留（现有实现）。
- 提示词模式下排序独立记忆（现状 sort='prompt' 已如此，保留）。
- 首次切换给一次性 tooltip：「按提示词读：同一句话交给不同模型，交出什么？」——给透镜一个语义包装（[识别]：看见模式名就懂用法）。
- v3 不把 Prompt 升为独立实体页（02 §6.3 非目标；374 件待归簇撑不起一级面），透镜就是 Prompt 在 IA 中的家。

### 4.5 空结果四出口

搜不到时（LIKE 搜索的信任风险点，02 E），空态必须给四条出路（[气味]不留死胡同）：

1. 放宽条件按钮（自动去掉最后一个筛选重查）
2. 「按提示词模式再看一次」（切透镜）
3. 去论坛求助（携带当前筛选词预填发帖）
4. 「这道题还没有？出一题」→ 出题候选出口（仅当筛选像题目意图时出现，M3）

## 10. 移动端优先策略

> 前提重申：移动端不是「缩小桌面」，是一等设计目标。现状已有 541 行独立移动适配区（01 §3.1 地层学），说明移动是「补丁」不是「目标」——本次按目标重做信息架构。

### 10.1 原则

1. **拇指区优先**：主动作放底部（TabBar/FAB/动作条），顶部只放导航与状态（[菲茨]：越近越大越快，拇指弧线决定布局）。
2. **触达 44×44px 底线**，行间可点元素间距 ≥8px（[触达]）；hover 语义在触屏不可靠 → 所有 hover 样式包 `@media (hover:hover)`，触屏用 `:active` 压平反馈（四法则的触屏映射）。
3. **信息密度分层**：L0 卡片 → L1 行 → L2 详情 → L3 证据；移动端默认呈现 L0-L1，L2 按需进入，L3 折叠（[披露]）。密度每降一层，同屏信息 ×2、交互 +1 步——用交互步数换可读性，在拇指屏上是赚的。
4. **单列一切**：移动端不出现双栏对比布局；对比类内容（证据表/对比行）横向滚动呈现且首列 sticky。
5. 手势只做两个：系统返回（不劫持）、列表下拉刷新（可选）；不发明自定义手势（[雅各布]）。
6. **一条缩放律**：移动端数值≈桌面 50%（border 2/4、shadow 4/8、间距/字号同比例——参考提炼 §一），以它收敛现网两套断点并存的适配债（t4 归一断点体系，本文先立纪律）。

### 10.2 底部导航（TabBar）

```
┌──────────────────────────────────┐
│        （页面内容）                │
├──────────────────────────────────┤
│  [首页] [作品] [上传◉FAB] [社区] [我的] │
└──────────────────────────────────┘
```

- 4 Tab + 中央上传 FAB（上传是站点核心转化动作，FAB 给它物理地位 [菲茨]）。
- Tab 映射：首页=/ · 作品=/demos · 社区=/forum · 我的=登录?/login:/user/:u（内含通知/设置入口）。
- 榜单/探索不进 TabBar：从首页入口胶囊与作品库顶部进入（[米勒]：TabBar 上限 5，榜单是低频二级）。
- 「我的」内聚：用户页入口 / 通知（未读徽章）/ 设置（主题/语言/偏好）/ 登出。通知不单独占 Tab（[米勒]），但未读红点在「我的」Tab 上镜像显示。
- 安全区：`env(safe-area-inset-bottom)` 适配（iPhone 底部横条）。
- 桌面/移动切换断点：<720 启用 TabBar，隐藏顶栏导航项（顶栏保留品牌+搜索+铃铛）。

| 首页 | §3.2 线框；入口 2×2 网格（44px） |

### 10.4 Demo 预览的可玩性（02 M 专项）

1. **点击播放**：海报帧+▶，不自动挂 iframe（省流量省电）。
2. **全屏**：Fullscreen API（iOS 降级固定定位层+隐藏顶栏）。

4. **横屏提示**：`orientation:portrait` 媒询下一次性横幅「横过来更好玩」。

- 具体预算（LCP/包体）由 t4 制定，本文约束：**移动端首屏请求数与布局位移是 IA 设计的验收项**（§14）。

## 11. 多主题与暗色（IA 侧硬约束）

### 11.1 token 三层架构（主题化的结构前提）

```
第 1 层 形状/尺寸原子（固定，不随主题变）：--border-w、阴影偏移三档（小 2/4、中 4/8、大 6/12，mobile/md——参考提炼 §一）、间距阶、字号阶、动效令牌（--b-dur/--b-ease）
第 2 层 色板原子（**每主题一组**，主题差异的第一现场）：
  纸白=现网五色基因（#ff6b6b/#4ecdc4/#ffe66d/#95e1d3/#f38181 + 纯黑纯白，01 §3.3 已逐值对齐）
  墨黑=参考色板系（#ff006e/#ccff00/#00d9ff/#ff9500）的暗色优化版（t4 逐色重验 AA；大面积底色一律用低饱和变体——参考提炼 §三）
第 3 层 语义 tokens（由本主题色板原子派生；**角色名跨主题不变**）：
  --paper/--paper-2/--paper-deep        （面）
  --ink/--ink-soft/--ink-faint          （文字，三档——顺手修掉 01 §3.4 的断 token）
  --line（边框线）--shadow-color（阴影色）
  --scrim（遮罩纱色：paper rgba(0,0,0,.55)/ink .70——t7 走查引入、t4 §3.4 入册的结构角色，组件层 backdrop 一律引 token）
  --accent-cta/--accent-ok/--accent-info/--accent-warn/--accent-hot（五个强调角色）
  --font-mono/--font-sans（补定义——01 §3.4 断引用）
第 4 层 组件 tokens：--btn-bg/--card-shadow/--stamp-rotate …（组件从语义层取值，禁止直接取色板原子）
```

- **主题=色板原子+语义层联合换表**：`html[data-theme="ink"]` 重定义第 2/3 层，第 4 层组件与全部布局零改动（stylekit 规范页「暗色需语义 token 不反相」的工程化表达）。

### 12.6 页面转场规范（v3.3 新增：页面间动效）

> 用户拍板：「页面内动效再多些，交互感强一些；页面间的动效也不要忘记。」

- **转场公式：旧页 0ms 硬切消失 + 新页 stamp-lite 登场**。新页 enter = opacity 0→1 + scale 1.02→1 + y 8px→0，250ms easeOutExpo（复用 `--b-ease-stamp: cubic-bezier(0.16,1,0.3,1)`）；旧页 leave = duration 0（无残影，等价瞬时卸载）。「盖章落位」语汇从弹层扩展到路由级——页面出现也是一次落章，与弹层/面板同一心智。
- **前进/后退同构**：不区分方向、不做左右滑动隐喻（[识别]：一种转场=一个心智模型；方向性转场是 App 心智，本站是文档流心智）。
- 令牌（**t9 接口建议**）：新增 `--b-dur-page: 250ms`；曲线复用 `--b-ease-stamp`。转场属**编排类**（节制红线 c 的 opacity 白名单成员）；count-up 的实现归属（composable/组件 token）同归 t9·04 侧，本文只定义触发面与节制口径。
- **Vue 实现注记（给 t9）**：RouterView 外包 `<Transition mode="out-in">`（现 App.vue 的 v-slot + KeepAlive 结构不变，Transition 包在 KeepAlive 外层）；leave 端给 0ms（无 leave 动画）；**KeepAlive 兼容注记**——缓存页（include 8 页）再激活时仍走 enter：回到页面有「落位感」，符合盖章语汇，且实例复用不重挂数据；`appear` 仅首路由生效一次；滚动位置由既有 scrollBehavior 管，转场不接管。
- **例外（不打转场）**：①`/forum/*` 双皮壳——域切换是「换场景」，硬切即可（转场反而暴露两套壳的接缝）②`/upload?slug=`（remountOnQuery 身份重挂）③弹层/抽屉/toast——用既有 stamp-in 微档，不走路由转场 ④admin 域内面板切换走 Tab march（§12.5 词汇表），不走路由转场。
- reduced-motion：转场全退场（旧页即时消失、新页直接显示）。
- 性能注：转场只动 transform/opacity（合成器通道，不触发 layout/paint）；enter 的结束态=静止态，转场结束后视觉与无转场完全等价；LCP 元素不得依赖转场才可见（enter opacity 从 0 起，250ms 内达 1——首屏指标由 t9 的预算口径裁定是否需要「首路由跳过转场」）。

## 14. 验收与风险

### 14.1 IA 验收清单（走查脚本，验收=真实操作不是看图）

| 角色 | 任务 | 通过标准 |
|---|---|---|
| 游客 | 从落地页 3 次点击内到达：一件作品的预览 /「哪个模型强」/ 本周神作 | 全部 ≤3 跳 |
| 游客 | 作品库筛选「DeepSeek+游戏」，移动端完成同样筛选 | 桌面 ≤2 次点击；移动 ≤3 次触达且条件可见 |
| 作者 | 匿名上传→看挂题申请状态→提议一道新题 | 全程无死胡同，申请状态可见 |
| 社区用户 | 关注某人→查粉丝名单→收到关注类通知（M3 后） | 名单可达、通知有触发 |
| 管理员 | 概览台 3 分钟内批量处理一批同 kind 候选；建一条互链公告 | 批量路径存在、互链免 API |
| 全体 | 移动端全部主要页 | 44px 触达、无横向溢出、LCP 预算达标（预算值 t4 定） |
| 全体 | 切墨黑主题后走查主要页 | 无字面色残留、对比矩阵全过、四通道层级不变 |
| 全体 | 抽验交互物理（CDP 计算样式，同动效规范 §6 方法） | hover=增影+左上抬起、active=压平（位移=阴影偏移）、过渡=150ms ease-out、无 blur 阴影、列表无逐项入场 |
| 全体 | 静止态旋转扫描（CDP getComputedStyle transform **反解**断言，与交互物理抽验同跑；stylelint 仅粗防线 warning，CDP 为权威门） | 任意页面无旋转的**文本承载容器**（静止 rotation=0°）；白名单豁免=印章/贴纸/徽章装饰（±1~2°）+ fun 彩蛋层（P3，data-fun）。**实现归一（t5 备忘）**：CDP 扫描器与对比度校验同原则单点实现（t4 CI 套件），03 引用不双写 |
| 全体 | 路由转场走查（含 KeepAlive 缓存页往返：/demos→/demo→返回） | 旧页 0ms 消失无残影；新页 stamp-lite 250ms 落位；缓存页回访仍走 enter；滚动位置不因转场丢失；forum/upload/admin 例外面板不打转场 |
| 全体 | reduced-motion 下转场与微交互抽查 | 旧页即时消失、新页直接显示（无 250ms 编排）；count-up 直接显示终值；铃铛 shake 退场 |
| 全体 | 同屏并发运动预算抽查（CDP/性能面板抽样） | 非用户触发的并发运动元素 ≤3；用户触发动效 ≤300ms 完成；首屏 stagger ≤8 项/总时长 ≤400ms；加载更多淡入 120ms 无 stagger |
