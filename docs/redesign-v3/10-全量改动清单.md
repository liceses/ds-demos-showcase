## 2. 前端改动明细

### 2.1 架构与工程
- `src/styles/`：style.css 6304 行保序拆迁为六层（tokens/base/components/layouts/pages/utilities）71 文件
- **tokens 三层**：primitives（L1 原子，含 --p-* / --k-* 双色板）/ semantic（L2 语义角色，存量名零改名别名桥）/ themes（L3 换装表）
- **多主题**：`data-theme` paper|ink + 跟随系统；FOUC 防闪内联脚本；硬切闸 250ms；墨黑=#141414 系+暖白影 #f5f2ea
- **动效体系**：b-stamp-drop 落下回弹 / b-stamp-lite 页面转场 / brutal-march 蚂蚁线 / 双速制（150ms 交互 + 350ms 编排）；R7 色切 0ms；R8 静止零倾斜（tilt 三令牌）
- **工程化**：stylelint（禁止项机器化 0 error/16 warning）→ vitest 冒烟三件（token 完备/对比度硬门/路由快照）→ CI 三步门 → 字体自托管（@fontsource，消灭 Google Fonts）

### 2.2 信息架构（IA）
- 顶栏：6→4 信息项（作品库/探索/排行榜/论坛→后改为搜索入位）→ 最终 v3 对称栅格 [1fr auto 1fr]（0.0px 偏差）+ 论坛出顶栏
- 首页枢纽：hero 双列 + 数字条 + 站点条带 01-05 + 公告横幅（横幅+弹层=公告唯一一级面）+ 侧栏解体
- 作品库：分面抽屉（钉住/bottom-sheet）+ 已选 chips + OR/AND 微文案 + 空态四出口
- 移动端：TabBar（4 Tab+FAB）+ 抽屉退役 + 44px 底线 + safe-area
- 论坛：纸条常驻恢复（用户原设计考古逐字还原）+ footer 链 + 404 卡 + TabBar 社区四路可达

### 2.3 组件体系
- 新组件：EntityPicker 基座（五变体：demo/model/task/topic/tag，搜索即选）+ SearchOverlay（三域并行）+ CopyButton + TagTip + AppTabBar + 精选管理面板
- 拆分：UploadView 1387→725（5 composable + 4 子组件，行为 diff=0，12 项冒烟 10 轮全过）
- 直改权：实体详情五区（概要直改/关系/生命周期状态机/审计/关联作品）

## 3. 后端改动明细

| 端点/能力 | 说明 |
|---|---|
| PATCH /admin/entities/{type}/{id} | 实体字段直改（白名单逐实体 + reason 审计理由） |
| POST /admin/tasks | **管理员直建题**（demo_slugs fail-fast，不经候选队列） |
| POST/DELETE /admin/tasks/{ident}/demos | Task↔Demo 挂载/摘除（by slug，双审计） |
| GET /admin/tasks/{ident} | 管理端详情（任何状态 + 归属全量含 pending） |
| POST /admin/tasks/{ident}/merge | merge 两步流（dry_run 预览→显式执行） |
| POST /admin/suggestions/batch-review | 收件箱批量（逐条独立审计，失败隔离） |
| PUT /admin/entities/tag/{id}/status | Tag 状态机候选/active/deprecated + 读口过滤 |
| /admin/featured 五端点 | 精选策展（添加仅 approved/排序/hero 置顶/移除） |
| GET /demos?featured=1 | 策展池按序（空池回落随机） |
| comment_count 口径 | 退役 Comment 表 → **论坛主题回复数**（讨论数） |
| 限流 | visit 30→120/min |

## 4. 运维与事故记录

- **计数恒 0 事故（09-04~09-06 生产）**：`counters.py _flush()` 的 `buf, _BUF = _BUF, {}` 元组赋值致 `_BUF` 变函数局部变量 → UnboundLocalError 被裸 except 吞 → 落库线程 30s 空转、计数从未持久化。修复 81c216d（buf = dict(_BUF); _BUF.clear() + 失败并回重试）+ 4 回归测试。**09-04~部署窗口计数增量不可找回**（内存设计固有代价）。部署前备份 app.db。
- **venv ABI 事故**：pydantic_core/cffi 装了 cp314 二进制进 Python 3.12 venv → 后端启动崩 → 前端 502。修复：强制重装 cp312 版本。
- **OSS AccessKey 泄露**：已弃用 wrangler.toml L20 明文 OSS Key ID——DEPLOY.md「安全待办」节已写轮换步骤，**待用户在阿里云执行**。
- **僵尸会话**：成员「失败」回合服务端仍执行（双写冲突/git restore 摧毁未提交工作）——interrupt_agent 处置；快照协议成为标准操作。
- **环境怪象**：vite 本地不清 outDir（build 链已改 clean+build）；沙箱 node rmSync(recursive) 被中和（clean 脚本逐条目删除）。
