6.1 交互物理 A/B 对照（R6）

废止参考 · 勿照抄

旧物理（现网 .btn）

hover: translate(4px,4px) + shadow:none——与参考物理相反（04 §2.2 R6 实锤 L159-162）。此处仅供对照「手感差异」。

判定：hover 物理反向 → v3.1 起废止

v3.1+ 定稿

新物理（参考站同构）

hover：阴影增大 + 左上抬起（不倾斜）；active：位移 = 阴影偏移 + 影清零 + 可叠 ±1° 微倾（--tilt-press，150ms 归位）；颜色一律 0ms 硬切（R7）。hover 样式包 @media (hover:hover)（触屏以 :active 反馈）。

判定：与 stylekit 交互物理一致（03 §12.5）

§11 页面转场

假页 A/B 切换

正式实现 = 路由级 <Transition mode="out-in">（04 §2.3.1 可抄范式）：旧页 0ms 硬切消失 + 新页 stamp-lite 登场（--b-dur-page 250ms · easeOutExpo）；前进/后退同构
编排类豁免口径：opacity 仅此上下文；交错 ≤3 元素 · 总时长 ≤400ms；reduced-motion 下直接换页

观察点：旧页瞬间消失（0ms，无离开动画——法则 02 硬切美学的页面级应用）；新页三块内容 8px 淡入交错登场（--b-stagger 30ms 步进 · b-rise-in 120ms/块）。切页期间 live 徽标 march 自动暂停（单实例守卫），450ms 后恢复。
