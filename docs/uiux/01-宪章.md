## 1.1 令牌（参考站自报）

| 项 | 参考站 | 本站 | 判定 |
|---|---|---|---|
| 圆角 | `0px` | 全站 0（stylelint error 级守护） | ✅ 一致 |

## 1.2 四法则（原文照录 + 本站落地）

### Rule 01 — Physical Crushing（按下压平）
> `active:translate-x-[Npx] active:translate-y-[Npx] active:shadow-none`；**N MUST equal the original shadow pixel value**。"Complete flattening — entity crushed into the surface."

**本站**：`.b-lift:active` 用 `--lift-flat` 表达"该元素影的偏移"，默认 `--sh-off-md`；实体卡/题目行走 `--sh-off-uw`（3px）。
**已纠正**：`.model-chip:active` 原为 `translate(1px,1px)` + 仍留 1px 影（半压），现为 `translate(2px,2px)` + 影清零。

### Rule 02 — Brutal Snap（硬切）
> `hover:bg-[#ffff00] duration-150 ease-out` —— 背景**硬切**，"NO gradients, NO opacity fade."

**本站**：R7 规定 transition 白名单只留 transform/box-shadow → 颜色 0ms 硬切 ✅ 同构；背景换色的实例：`.dv-next-card:hover`（换 `--yellow`）。
**待办**：本章只确认"快照式切换"这一机制；"哪些组件 hover 该换底"属阶段 2 的组件规范。

### Rule 03 — Zero Rounding Easing（无弹性）
> `transition-all duration-150 ease-out`；"No spring overshoot, no elastic settling."

**本站**：`--b-dur/--b-ease` ✅。注意**编排层**（入场盖章 `b-stamp-in`/`b-stamp-drop` 的 60% 过冲）与参考站不冲突 —— 参考站自己的 `brutal-stamp` 关键帧同样有过冲；Rule 03 约束的是**交互过渡**。

### Rule 04 — Heavy Focus（悬停加重）
> 卡片：`hover:shadow-[12px_12px_0px_0px_rgba(255,0,110,1)] hover:bg-[#ffff00]` —— **影变大 + 换强调色 + 背景硬切**。
> 按钮三态表：Default `6px` → Hover `10px` + `-translate-1`（抬起）→ Active 全压平。

**本站**：`.card-hover:hover` = 8px → **12px 红** ✅ 与 Rule 04 逐值一致（颜色用本站 `--red`）。
**已纠正**：`.card-entity` 族曾是 8px → **6px（影缩）**，四处违反 Rule 04 / R6，现为 3px → 5px（`--shadow-entity(-hover)`）。
**有意偏离**：按钮 hover 走"**影保持 + 抬起**"（`button.css` 既有口径：8px 档保持、-2px 抬起 = 表观 10px 增影），而非参考站的影 6→10 增长；理由与复审条件见 `08-例外登记.md` E-1。

## 1.3 禁止项对照

| 参考站禁止 | 本站机器化守护 | 状态 |
|---|---|---|
| `rounded-lg/md/xl`（软化棱角） | stylelint `declaration-property-value-disallowed-list` 非零圆角 error | ✅ 已覆盖 |
| `shadow-sm/md/lg/xl/2xl`（模糊影） | stylelint 禁 `inset` 模糊；硬影格式由令牌收口 | ⚠️ 部分（模糊影只用 inset 这一条规则拦，见 09-对照表 D-4） |
| `bg-gradient-*`（渐变） | 无专门规则；全站仅 1 处渐变（`.b-march` 蚂蚁线，硬边条纹豁免） | ⚠️ 待补（09-对照表 D-5） |
| `border-gray-*/slate-*`（非纯黑边框） | stylelint 颜色只许 `var()`（消费侧） | ✅ 已覆盖 |
| fade / opacity 淡入（交互反馈层） | R7：transition 白名单 + 编排类豁免（`motion.css` 顶部注释） | ⚠️ 待补机器化（09-对照表 D-6） |
