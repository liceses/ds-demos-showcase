# 02 · 原则（灵魂清单 / 不做清单 / 颜色语义）

## 2.1 灵魂清单（动不得）

| # | 原则 | 实现锚点 | 谁在钉 |
|---|---|---|---|
| P1 | **硬边**：全站零圆角 | stylelint `border-radius` error 级 | 机器化 ✅ |
| P2 | **粗黑边框**：桌面 4px / 移动 2px | `--border-w-md` + `@720` 减半 | 令牌 ✅ |
| P3 | **硬偏移影**：`Xpx Xpx 0 0`，禁止模糊 | 硬影令牌族 + stylelint 禁 `inset` 模糊 | 部分（D-4） |
| P4 | **静止零倾斜**（R8）：承载文字的元素静止态 `rotate: 0`；倾斜只许 ①装饰件常驻 ②入场轨迹 ③按压瞬时 ±1° | `--tilt-rest/--tilt-deco/--tilt-press` | CDP 反解（粗防由 review 承担，见 09 表 D-1） |
| P5 | **色切 0ms**（R7）：颜色不进 transition；过渡只许 transform / box-shadow | `motion.css` 白名单 + 各组件 transition 声明 | 部分（D-6） |
| P6 | **黄 = 唯一行动色**：主 CTA 才用黄；统计/计数不用行动色 | 探索页 `.mini-stat` 白底黑边（scoped 复位） | 护栏（exploreRedesign 测试） |
| P7 | **五强调色各有语义**：红=行动/危险 黄=行动 青=链接/信息 薄荷=成功 珊瑚=强调卡 | `--p-*` / `--k-*` 两套（纸白/墨黑） | 令牌 + 08 例外 E-2 |
| P8 | **动效双速制**：交互 150ms / 编排 350ms；无弹性回弹 | `--b-dur` / `--b-dur-stage` / `--b-ease(-stamp)` | 令牌 ✅ |
| P9 | **字号与间距必须走令牌**（`--fs-*` / `--sp-*`）：档内字面值不许出现，档外值须登记理由 | 两张表（`primitives.css`） | 门禁⑧（档内=0 + 档外白名单） |

## 2.2 不做清单

| 不做 | 理由 |
|---|---|
| 圆角、模糊影、渐变、半透明玻璃态 | 与硬边野兽派语汇冲突（参考站明确禁止） |
| `transition: all` | 会把颜色属性一起动画化，违反 P5 |
| 交互动效用 opacity 淡入 | 反馈必须是"硬切/位移/影变"；opacity 仅限编排层（入场/转场） |
| 弹性/回弹缓动（spring、elastic） | 参考站 Rule 03 |
| 在组件文件里裸写 hover/active 物理 | 违反 `06-微交互.md`；门禁② |
| 手写令牌表 / 手写迁移清单 | 会漂移（本轮已两次），必须由脚本生成 |

## 2.3 颜色语义（消费侧纪律）

1. **消费侧只许 `var(--…)`**：`color/background-color/border-*-color` 里的字面色值一律违规（stylelint warning→error 两波）；色板原子（`--p-*`/`--k-*`）只在 `tokens/` 里出现字面 hex。
2. **厂商色只许出现在**：模型格的图标块底色 / 顶带 / 左带（`.explore-tile` + `.explore-band--*`）。卡片本体永远纸底 + 黑边 —— 否则页面会被十几个品牌色染花。
3. **统计数字不用行动色**：计数、评分等一律纸底黑边（黄只留给"点了会发生事情"的地方）。
4. **墨黑主题靠换绑不靠重写**：新增颜色一律走语义角色（`--ink/--paper/--red…`），墨黑主题在 `themes.css` 换绑；**不许**在组件里写 `[data-theme='ink'] .xxx` 覆盖（会漏翻面）。
5. **对比度**：正文/正文级 UI ≥ 4.5:1，大字号与图形 ≥ 3:1（矩阵见 `07-无障碍.md`，进 CI 属阶段 2）。

## 2.4 布局与信息密度的两条经验（探索页两轮实测所得）

- **空实体必须降权**：0 内容的格子与有内容的同权，会把首屏最贵的位置浪费掉（实测移动端"题目"段被挤到 795px）。
  现在统一走 `partitionByContent()`：有内容在前、空的折叠成一行；**整段全空则不折叠**（否则页面看起来是空的）。
- **页面 0 图是缺陷不是风格**：探索页原本一张图都没有，读者无法判断"这道题大概长什么样"。题目行封面（200px 缩略图）
  是这轮的解法，预算：8 张 ≤ 120KB（实测 27.3KB）。
