# 04 · 组件规范（七态矩阵）

> 每个组件都要回答**七态**：rest / hover / active / focus-visible / disabled / loading / `hover:none`（触屏），
> 外加 reduced-motion 与键盘可达性。**没写的状态 = 未定义**，不是"默认没问题"。
> 状态取值一律引令牌（`03-令牌表.generated.md`），不写 px 字面值。

## 4.1 矩阵模板

| 态 | 视觉 | 实现 |
|---|---|---|
| rest | 影 = `--lift-sh` | `.b-lift`（库） |
| hover | 抬起 `--lift-*` + 影 = `--lift-sh-hover` | `.b-lift:hover`（仅 `@media (hover:hover)`） |
| active | 位移 = `--lift-flat`、影清零、0ms 硬切 | `.b-lift:active` |
| focus-visible | `outline: 4px solid var(--ink); outline-offset: 2px` | 组件自带（库不管焦点） |
| disabled | 影清零 + `opacity` 降（`aria-disabled` 或原生 `disabled`） | 组件 |
| loading | 蚂蚁线（`.b-march`）或骨架屏；**不许禁用按钮但无反馈** | 组件 |
| `hover:none` | hover 物理不生效；反馈由 `:active` 承担 | 库的 `@media (hover:hover)` |

## 4.4 组件命名与文件纪律

1. 组件样式落在 `styles/components/<name>.css`（通用）或 `styles/pages/<page>.css`（页面专属）。
2. **同一选择器只许一个文件定义**（门禁①，交互选择器已强制；其余选择器按"谁改谁拆"逐步收）。
3. 层序即层叠：`tokens → base → layouts → components → pages`（`styles/index.css` 的 @import 顺序）。
   页面文件覆盖组件文件是允许的**语境覆盖**（如论坛壳减档），但必须用**语境前缀**（`.forum-shell .btn`），
   不许用裸选择器 —— 裸选择器会泄漏到全站（本轮实测：论坛的 3px 按钮档泄漏成了全站档位）。
