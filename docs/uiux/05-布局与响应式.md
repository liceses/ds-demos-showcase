# 05 · 布局与响应式

## 5.1 断点（唯一白名单）

| 断点 | 语义 | 典型变化 |
|---|---|---|
| 480px | 小屏手机 | 单列、字号收一档 |
| 640px | 手机 → 平板 | 题目行换行、CTA 归位 |
| **720px** | **50% 律收敛点** | 边框 4→2px、影偏移减半、抽屉/底栏切换 |
| 721px | 720 的互补值 | 与 720 配对使用，**不留缝隙档** |
| 1024px | 平板横屏 / 小桌面 | 栅格列数变化 |
| 1025px | 1024 的互补值 | 同上 |
| 1280px | 桌面 | 页宽顶格 |

- 白名单由 stylelint `media-feature-name-value-allowed-list` 守护（**error 级**）；新增断点必须先改本章与 stylelint 配置。
- 媒体查询是**视口**驱动的：容器宽度模拟测不出断点行为（验收必须用独立 iframe / 真实窗口）。

## 5.2 页宽三档

| 令牌 | 用途 | 谁在用 |
|---|---|---|
| `--w-page` | 默认内容宽（列表页、表单页） | `.container` |
| `--w-wide` | 宽内容（探索页/作品库等栅格页） | 路由 `meta.wide` → `.shell-wide` |
| `--w-read` | 阅读宽（正文、关于页） | 阅读类页面 |

**路由决定壳宽**：同一页里"顶栏宽度 ≠ 内容宽度"是缺陷（用户实测反馈过"作品集 tab 与顶栏不一致"），
现由 `route.meta.wide` 统一决定。

## 5.3 50% 单一缩放律（R1/R2）

| 项 | 桌面 | ≤720 |
|---|---|---|
| 边框 `--border-w-md` | 4px | 2px |
| 影 `--sh-off-md/lg/xl/2xl` | 4/6/8/12px | 2/3/4/6px |
| 影 `--sh-off-sm/uw` | 2/3px | **不减**（已是下限，既有约定，见 08 例外 E-3） |
| 抬起量 `--lift-x/--lift-y` | -2px | 同值（位移量小，减半会看不出来） |

**同一元素只减一次**：不允许"组件自己写 `@media` 再减半"（会双跳）。减半只在 `tokens/primitives.css` 一处发生。

## 5.4 首屏预算（实测口径）

| 页 | 指标 | 当前值（生产规模镜像） |
|---|---|---|
| 探索页 | 首屏图片总量 | 8 张题目行封面 **27.3KB**（预算 ≤120KB；缩略图 200px ≤25KB 单张） |
| 探索页 | 移动端页面总高 | 3387px（加封面后 +196px，+6.1%） |
| 任意页 | 单页图片总请求 | 封面走 200px 缩略图；原图只在详情页出现 |

**测量方法**：`performance.getEntriesByType('resource')` 实测字节（不是估算），
并用 `document.images.every(i => i.naturalWidth > 0)` 断言图真的解码了（`loading="lazy"` 的图在视口外永不解码，
只截图不看这个会把"一排空框"当成通过）。

## 5.5 移动端（合并自 `docs/移动端适配.md`）

1. 底栏（TabBar）只在 ≤720 出现；顶栏导航在移动端折叠为图标簇。
2. 触达尺寸：可点元素 ≥44px（探索页自测已达标；**顶栏共享控件（墨/EN 39px、tag-chip 40px）仍未达标**，
   属组件级改动，记在 08-例外登记 E-6）。
3. 移动端不做 hover 语义（见 `06-微交互.md` 6.5）；`hover:none` 下反馈由 `:active` 承担。
4. 横向溢出为零：每个断点都要断言 `scrollWidth === clientWidth`。
