# 06 · 微交互（hover / active / 触屏 / 减少动效）

> 本章是**规范条款**，每一条都对应 `09-规范↔门禁对照.md` 里的门禁，或登记在 `08-例外登记.md`。
> 实现只有一处：`frontend/src/styles/components/lift.css`（微交互库）。

## 6.1 三条不变量

| # | 条款 | 依据 | 谁来钉 |
|---|---|---|---|
| M1 | **hover = 抬起 + 影增大**，影**绝不许缩** | 参考站 Rule 04；本站 R6 | 门禁②（基线只收窄）+ 本节 6.3 档表 |
| M2 | **active = 压平进表面**：位移量 = 该元素影的偏移像素、阴影清零、0ms | 参考站 Rule 01 | 门禁②（库外不许写 active 物理）+ 6.4 |
| M3 | **过渡只许 transform / box-shadow，150ms，ease-out**；颜色 0ms 硬切，禁渐变/淡入 | 参考站 Rule 03 + R7 | 门禁⑥（硬影/渐变/色切）+ stylelint |
| M4 | **两种合法 hover 技法**：① 卡片/行卡 = 影 ×1.5 **增影**；② 按钮 = 影**保持原档**、靠抬起 2px 形成表观增影（用户 2026-09-13 拍板） | 参考站 Rule 04 + 用户裁决 | 门禁③（卡片档表）+ 门禁⑨（按钮禁增影） |

## 6.2 写法：组件只声明变量

```css
/* 组件（自己的文件里）——只声明值，不写物理 */
.my-card {
  --lift-sh: var(--shadow-entity);        /* 静止影（无影组件写 none） */
  --lift-sh-hover: var(--shadow-entity-hover); /* hover 影（省略 = 保持静止影，即"只抬不增影"） */
  --lift-flat: var(--sh-off-uw);          /* Rule 01 的压平位移，必须等于 --lift-sh 的偏移 */
}
```
```html
<!-- 模板 -->
<a class="my-card b-lift">…</a>
```

库提供：`@media (hover: hover)` 触屏防粘滞、`:active` 压平 + `--tilt-press` 微倾、
`prefers-reduced-motion` 退场。**这三件事以前各组件各写各的**（触屏守卫全站只有 `.btn` 有）。

## 6.3 影档表（hover = 静止档 × 1.5，取整到整数像素）

| 静止档 | 值 | hover 档 | 值 | 用在哪 |
|---|---|---|---|---|
| `--sh-off-sm` | 2px | `--sh-off-hov-sm` | 3px | 小 chip（`.model-chip` 等） |
| `--sh-off-uw` | 3px | `--sh-off-hov-uw` | 5px | **实体卡 / 题目行**（用户拍板档） |
| `--sh-off-md` | 4px | `--sh-off-hov-md` | 6px | 中档卡（阶段 2） |
| `--sh-off-lg` | 6px | `--sh-off-hov-lg` | 9px | 参考站按钮档（阶段 2） |
| `--sh-off-xl` | 8px | `--sh-off-hov-xl` = `--sh-off-2xl` | 12px | 大卡；**与参考站 Rule 04 逐值一致（8→12）** |

`@720` 减半律：桌面对半（md/lg/xl/2xl）；`sm`/`uw` 不减（`primitives.css` 既有约定，见 08-例外登记）。
这条律同时解释了两个"手感事实"：参考站卡片 **8→12**、用户认可的题目行 **3→5**。

## 6.4 active（Rule 01）逐档对照

| 元素 | 静止影 | 压平位移 | 备注 |
|---|---|---|---|
| 实体卡 / 题目行 | 3px | `translate(3px,3px)` | `--lift-flat: var(--sh-off-uw)` |
| 小 chip | 2px | `translate(2px,2px)` | 原先写的是 `translate(1px,1px)` + **仍留 1px 影** = 半压，已纠正 |
| 无影卡（`.card-hover`） | none | `translate(12px,12px)` | 顶格档 |
| 按钮（`.btn`） | 4px / 8px 变体 | `translate(var(--sh-off-md))` | 阶段 2 接线到库 |

## 6.5 触发条件与无障碍

- hover 物理**必须**包在 `@media (hover: hover)` 里：触屏上 hover 会"粘"住（点一下之后一直保持悬停态）。
- `prefers-reduced-motion: reduce` → 过渡与位移退场（静态影保留：静止变换 ≠ 动画）。
- 键盘：`:focus-visible` 提供 4px 焦点环（见 `07-无障碍.md`），**不靠 hover 表达可交互性**。

## 6.8 顺手修掉的三个存量缺陷（本轮实测发现）

1. **跨文件同名覆盖**：`.ac-card:hover`（motion.css 8px 红 vs admin-shell.css 6px 墨）、`.uw-type:hover`（motion.css 8px 墨 vs upload-wizard.css 6px 墨）—— 按导入顺序后者胜，**前者从未生效**。已删死规则。
2. **论坛按钮物理泄漏到全站**：`forum-lite.css` 的 `.btn:hover/.btn:active/.btn-primary…{box-shadow:3px}` 是**裸选择器**（注释写的是"论坛壳内"），而它在 `index.css` 里排在 `button.css` 之后 → 全站按钮的影档被从 8px 改成 3px。已加 `.forum-shell` 前缀，主站按钮回到 `button.css` 口径（实测：`.btn-primary` 3px → **8px**）。
3. **入场动画锁死 hover 抬起**：`.animate-in { animation: … both }` 的 `both` 让动画结束后继续锁住 `transform: translateY(0)`（CSS 动画优先级高于普通声明），作品卡的 hover 抬起**从来没生效过**（只有影变）。改为 `backwards` 后实测抬起恢复（`matrix(1,0,0,1,-2,-2)`）。
