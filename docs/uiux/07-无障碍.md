# 07 · 无障碍

> 目标：**WCAG 2.1 AA**（`04-设计系统与架构提案.md §3.7` 既定的验收红线，当时没进 CI，本章负责把它变成可执行的清单）。

## 7.1 焦点

| 条款 | 值 | 实现 |
|---|---|---|
| 焦点可见 | `outline: 4px solid var(--ink); outline-offset: 2px` | `.btn:focus-visible` 等；**不许** `outline: none` 而无替代 |
| 焦点环在墨黑主题 | 自动翻暖白（`var(--ink)`） | 令牌换绑 ✅ |
| 键盘可达 | 所有交互元素可 Tab 到、Enter/Space 触发 | 用 `<button>/<a>` 而非 div+click |
| 焦点不丢 | 折叠/抽屉开合后焦点保持 | 探索页折叠控制器、预览全屏（`useDismissOnEsc`） |

## 7.2 触达尺寸

- 可点元素 ≥ **44×44px**（移动端）；桌面 ≥ 32px。
- 现状：探索页已逐条收紧到 44px；**顶栏共享控件墨/EN（39px）、tag-chip（40px）仍未达标**（E-6，组件级改动）。

## 7.3 对比度（每主题一张矩阵，**已进 CI**：`frontend/tests/designSystem.test.ts` ⑦）

> 下表是设计值；**门禁从 `tokens/*.css` 实算并断言 ≥4.5:1**（改令牌改坏对比度会直接测试红），
> 同时禁止墨黑主题把强调色写成字面 hex。

| 组合 | 纸白主题 | 墨黑主题 | 要求 |
|---|---|---|---|
| `--ink` on `--paper` | `#000` / `#fff` = 21:1 ✅ | `#f5f2ea` / `#141414` = 15.07:1 ✅ | ≥4.5:1 |
| `--ink-soft` on `--paper` | `#555` / `#fff` = 7.5:1 ✅ | `#b8b2a4` / `#141414` ≈ 8.3:1 ✅ | ≥4.5:1 |
| 行动色底（黄/薄荷）+ `--on-accent` 字 | 黑字 on 黄 ≈ 19:1 ✅ | 荧光系 + 暖白（`themes.css` 换绑） | ≥4.5:1 |
| 错误色 `--err` | `#a4001d`-系 | `#ff8a8a` / `#141414` = 8.12:1 ✅ | ≥4.5:1 |
| 厂商色底 + 图标 | 按底色亮度自动切黑/白图标（`iconInkFor()`） | 同 | ≥3:1（图形） |

## 7.4 语义与替代文本

| 条款 | 例子 |
|---|---|
| 装饰性图 `alt=""` | 题目行封面、卡片封面（旁边有标题） |
| 有意义图给 `alt` | 作品详情主图用作品标题 |
| 图标 `aria-hidden` | 厂商图标块、装饰 SVG |
| 状态位 | 折叠 `aria-expanded` + `aria-controls`；错误态 `role="alert"` |
| 语言 | `<html lang>` 随 i18n 切换；正文语言与作品语言分离（`demo.lang`） |

## 7.5 减少动效（`prefers-reduced-motion`）

- 交互过渡与位移退场（微交互库统一处理）；
- 编排类（页面转场、交错入场、蚂蚁线）退场；
- **静态变换保留**：静止倾斜/硬影不是动画，不因 reduced-motion 改动（避免主题间视觉漂移）。

## 7.6 键盘与读屏的验收动作（每次改动相关页面时做）

1. 只用 Tab/Shift+Tab/Enter/Space/Esc 走完主要流程；
2. 折叠区、抽屉、全屏预览：开合后焦点位置正确，Esc 语义归属正确（见 `docs/预览架构与排坑记录.md` 坑六）；
3. 读屏抽查：图片替代文本、按钮可读名（不用"点这里"）、错误提示会被播报（`role=alert`）。
