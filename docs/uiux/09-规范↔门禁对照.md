## 9.3 验收口径：等值替换怎么证

### 护栏设计红线（a295a68 CI 事故换来的）

1. **hash / 快照类断言必须归一化环境差异**：行尾（CRLF vs LF）、路径分隔符、大小写。
   事故现场：`docs/uiux/.generated.hash` 覆盖 `tokens/*.css` 的**文件内容**，而这两个文件在
   Windows 工作区是 CRLF、CI 检出是 LF → 同一个提交算出两个 hash（本地 `b7403aa9…` 绿、
   CI `b82c31c1…` 红）。**只在单一平台成立的护栏等于没有护栏** —— 现在两处都 `replace(/\r\n/g, '\n')`。
2. **基线类断言按"值"比对，不按"字节"**：迁移基线（物理/档外值）只比较值的集合与计数，
   不比较文件内容，天然跨平台。
3. **涉及身份/权限的改动，必须跑"未登录态"验收；登录态的绿灯不算数。**
   事故现场：全局 401 → 跳登录 的拦截器 + 作品页无条件的 `recordView()`（要身份）
   ⇒ 匿名读者一进作品页就被弹登录页；而我此前所有验收都跑在已登录管理员会话上（`SHOT_LOGIN=1`），
   匿名路径**从未被走过**。详见 `log/2026-09-13-匿名访客被弹登录.md`。
   匿名验收口径：不登录打开 8~9 个公共页，断言 ① `location.pathname` 未被改
   ② **真实 401（排除设计内的 `/auth/me`）为 0** ③ 正文正常渲染（标题/评分/评论在）。
   机制侧护栏：`frontend/tests/authFlow.test.ts`（`silent401` 开关 + 后台可选调用必须静默 + 调用点必须带登录守卫）。

字号/间距收编是**等值替换**，所以验收口径不是"看着差不多"，而是：

1. **像素比对**：9 页 × 3 断点，改前 / 改后 / **对照组**（同状态连拍两次）三路比 ——
   对照组用来剔除动态页（首页副标题轮换、计数、相对时间：27 张里 16 张自比就不同）。
   稳定页结果：**6/10 逐字节一致**。
2. **反向实验（更硬的一条）**：把 codemod 的 1830 处 token 引用整体反向回 px，
   在浏览器里数"含 `var(--sp-/--fs-)` 的规则数"：反向态 **0** 条、还原态 **671** 条，
   **页高两种情况都是 2004** —— 证明收编本身与布局无关（不是"差不多"，是"规则数差 671 条、布局不动"）。
3. 已知残留：探索页 1024 的页高在"改动前单次采样"里是 2003、现在稳定 2004（+1px，三次重拍逐字节一致）。
   本轮改动中触碰该页面的项目（库钩子只加 box-shadow/transition、其余都在别的页面）**按检查都与布局无关**，
   故记为**采样态差异**；若要彻底钉死，下一步可用 `git stash` 复现改动前整态再拍一次（见 log 记录）。
