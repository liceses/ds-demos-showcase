# 前端优化与重构总览

> 本文汇总本轮前端优化/重构的全部改动，便于回溯与后续维护。

## 一、AdminView 拆分（性能最优）

- 后端新增轻量统计接口 `GET /admin/stats`（Demo 状态计数 / 用户数 / 存储信息），前端 `getAdminStats()` 接入
- AdminView 从 1215 行拆成 **127 行纯壳**（Tab + 概览 + 分发）
- 7 个自包含 Tab 组件（`src/components/admin/`）：
  - `AdminReviewSection` / `AdminDemosSection` / `AdminTagsSection` / `AdminForumSection` / `AdminUsersSection` / `AdminAnnouncementsSection` / `AdminSettingsSection`
- 首屏只请求 stats，各 Tab 进入时按需自加载（性能最优）

## 二、列表与状态抽象

- `composables/useListPage.ts`：服务端分页列表通用状态（已迁移 ForumList / Leaderboard）
- `composables/useLocalPagination.ts`：本地筛选分页（已迁移 AdminDemos）
- `stores/tags.ts`：`listTagKeys` 全局缓存（已接入 TagPicker / TagListView / AdminTags / UploadView）
- `utils/error.ts`：`errorMessage` 统一 429/普通错误（论坛发帖/回复/举报已接入）
- MarkdownRenderer 渲染缓存（Map，>500 自动清空）

## 三、CSS 拆分

- `style.css`（3835 行）→ `src/styles/`：
  - `base.css`（2243 行）
  - `tag-picker.css` / `home.css` / `demos.css` / `admin.css` / `tag-strip.css` / `sponsor.css` / `rating.css` / `markdown.css` / `forum.css`
- `main.ts` 按原级联顺序导入（base → feature → markdown → forum）

## 四、占位小组件

- `LoadingRow.vue` / `EmptyBox.vue` / `SectionHead.vue` / `SkeletonCard.vue`
- 已迁移：ForumList / Leaderboard / AdminDemos / AdminReview / TagDetail
- 骨架样式在 `styles/base.css`

## 五、论坛功能（前面已完成）

- 论坛子站独立壳 + 牛皮纸视觉
- Demo 讨论打通（ForumThread）、内部链接富卡片、公告互链
- 论坛管理后台（主题/回复/举报）
- 论坛列表 demo 缩略图 chip

## 六、约定

- 列表页优先用 `useListPage` / `useLocalPagination`
- 标签数据统一走 `useTagsStore`
- 错误提示统一 `errorMessage`
- 新公共组件放 `src/components`，composable 放 `src/composables`，样式放 `src/styles` 对应文件
