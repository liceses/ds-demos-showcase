# 前端重构记录（结构优化 / 抽象复用）

> 目标：优化代码结构、提高抽象与复用。本文件记录已完成项与后续待做项。

## 已完成（首批低风险重构）

### 1. 新增公共 `MarkdownEditor.vue`
- 封装「textarea + 编辑/预览切换 + 300ms 防抖预览 + MarkdownRenderer」
- Props：`modelValue / rows / placeholder`；`v-model` 双向绑定
- 替换使用点：
  - 管理后台公告编辑/新建表单
  - 论坛发帖正文
  - 论坛主题详情回复框
  - Demo 讨论（ForumThread）回复框
- 移除 4 处重复的 `preview` 状态与切换样板

### 2. 新增公共 `PaginationBar.vue`
- 封装「上一页 / 页码 / 下一页」
- Props：`page / total / pageSize`；`@change(page)`
- 替换使用点：论坛列表、排行榜、管理后台 Demo 列表

### 3. 统一相对时间 `utils/time.ts`
- 新增 `timeAgo()`；`utils/announcement.ts` 改为 re-export
- ForumListView 移除本地重复实现

### 4. 删除死代码
- `CommentTree.vue`（旧评论系统已下线，无引用）
- `TagChip.vue`（无引用）
