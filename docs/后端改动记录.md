# 后端改动记录（近期）

> 记录近期为配合前端而做的后端接口/模型改动，供联调与排查。

## 1. 标签：`TagKeyValueOut` 增加 `id`

- **文件**：`backend/app/schemas.py`、`backend/app/routers/tags.py`
- **改动**：`GET /tags/tag-keys` 返回的 fixed value 增加 `id` 字段
- **原因**：`PUT /tags/admin/values/{tag_id}/group` 需要 `tag_id`，之前前端拿不到 id 导致 422
- **影响**：前端 `TagKeyValue.id` 可用；分组/合并管理正常

## 2. 论坛：新增 `GET /forum/admin/replies`

- **文件**：`backend/app/routers/forum.py`
- **接口**：`GET /forum/admin/replies?topic_id=&status=`
  - `topic_id`：可选，按主题过滤
  - `status`：可选，`normal | hidden | reviewing`
  - 返回：`ForumReplyOut[]`（含 `status`）
- **原因**：新用户回复进入 `reviewing`，公开 `GET /forum/topics/{id}/replies` 只返回 `normal`，管理端之前无法看到审核中的回复
- **影响**：管理后台回复管理可查看/审核/删除 `reviewing` 回复

## 3. 论坛：`ForumReplyOut` 已含 `status`

- **文件**：`backend/app/schemas.py`
- **说明**：`ForumReplyOut` 一直有 `status` 字段（`normal | hidden | reviewing`），前端据此提示「已提交，等待审核」
