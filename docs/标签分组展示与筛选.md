# 标签分组展示与筛选（实现文档）

> 让所有出现标签的地方都使用「分组视图」，避免 model 等上百个值堆成一大片；作品集筛选隐藏零引用标签。

## 一、分组展示统一

### 分组规则
- 优先使用后端返回的 `group` 字段
- 没有 `group` 时按厂商前缀猜测：`dsv/deepseek → DeepSeek`、`gpt/o1/o3 → OpenAI`、`claude → Anthropic`、`gemini → Google`、`qwen → 阿里`、`doubao → 字节`，其余归「其他」

### 涉及文件
| 文件 | 作用 |
|---|---|
| `src/utils/tagGroups.ts` | `guessVendor()` + `groupedTagValues()` 分组工具 |
| `src/components/GroupedTagValues.vue` | 只读分组 chips 组件（支持 active 高亮、搜索高亮） |
| `src/views/TagListView.vue` | 标签页右值面板改分组展示 |
| `src/views/TagDetailView.vue` | 同键切换改分组展示 |
| `src/components/admin/AdminTagsSection.vue` | 管理后台键管理 fixed 值列表分组展示 |
| `src/views/DemosView.vue` | 作品集筛选条所有 fixed 键走厂商/分组视图 |
| `src/components/TagPicker.vue` | 上传/发帖选择器（原本已分组，保持一致） |

### 行为
- 只有一个分组时（如 `type` 全归「其他」）退化为普通平铺，不显示多余组标签
- 多个分组时显示黄色组名 + 组内 chips
- 搜索高亮（`search-hit`）在分组视图下保留

## 二、作品集筛选隐藏零引用标签

- `DemosView.filterGroups` 源头过滤 `demo_count === 0` 的值
- 整键所有值都为零引用时，整行隐藏
- 效果：筛选条只显示有实际作品的标签

## 三、验收

- 标签页 / 标签详情 / 管理后台 / 作品集筛选 / 上传发帖选择器，model 等大键都按厂商分组展示
- 作品集筛选不出现引用数为 0 的 tag
- 搜索高亮、选中态在分组视图下正常
