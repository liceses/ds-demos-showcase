# 标签分组管理（实现文档）

> 管理后台「标签管理」内的分组 / 合并功能，与键管理合并为一个界面。

## 一、后端接口（已实现）

| 接口 | 用途 |
|---|---|
| `GET /tags/admin/groups?key=model` | 列出该 key 的 group 分布：`{key, groups:[{group,count}], ungrouped}` |
| `PUT /tags/admin/groups/{key}/{group}` | 重命名 group，body `{new_group}` → `{updated, new_group}` |
| `DELETE /tags/admin/groups/{key}/{group}` | 清除 group（该组所有值变未分组）→ `{cleared}` |
| `PUT /tags/admin/values/{tag_id}/group` | 给单个固定值设/清 group，body `{group}` |
| `POST /tags/admin/merge` | 合并标签，body `{from_key, from_value, to_key, to_value, dry_run}` → `TagMergeResult` |

`TagMergeResult`：`{merged, removed_dups, affected_demos, deleted_source, dry_run}`

**关键前提**：`GET /tags/tag-keys` 的 `TagKeyValueOut` 必须返回 `id`，否则 `PUT /tags/admin/values/{tag_id}/group` 会收到 `undefined` 报 422。

## 二、前端实现（融入新架构）

### 文件
- `src/components/admin/AdminTagsSection.vue`：分组工作台嵌入「键管理」右侧
- `src/components/admin/TagMergeModal.vue`：合并弹窗（先 dry_run）
- `src/api/index.ts` / `mock.ts` / `types.ts`：API 与类型
- `src/stores/tags.ts`：操作后 `refresh()` 统一刷新

### 交互
- 在「键管理」选择 **fixed 键** 后，右侧显示「分组管理」区块：
  - **分组卡片**：组名 + 数量 + 成员值；操作：重命名（弹窗）/ 删除组（确认）
  - **未分组卡**：每个值旁下拉直接归类；支持 checkbox 多选 + 批量归入
  - **搜索**：按 value 过滤组内/未分组
  - **合并标签**：独立入口 → `TagMergeModal`
- 合并弹窗流程：
  1. 填源值（可手动输入）
  2. 选目标值（下拉，显示 demo 数）
  3. 「预览合并」→ `dry_run:true`，展示：引用迁移 / 重复移除 / 受影响 Demo / 源值删除
  4. 「执行合并」→ `dry_run:false`

## 三、常见报错排查

| 现象 | 原因 | 修复 |
|---|---|---|
| 422 `tag_id` invalid integer / undefined | `tag-keys` 没返回 `id` | 后端 `TagKeyValueOut` 补 `id`，`tags.py` values 带 `t.id` |
| 合并预览显示 0 | 源值/目标值不存在或目标值未创建 | 先确认目标值已存在（后端要求目标标签已创建） |
| 跨 key 合并 | 不支持 | 后端限制同 key 合并 |

## 四、验收

- 管理员能分组分布/重命名/清除/值归类/批量归入
- 合并前能看到影响 Demo 数，确认后才执行
- 分组/合并操作后 `tagsStore.refresh()`，公开页面分组即时生效
