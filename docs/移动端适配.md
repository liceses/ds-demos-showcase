# 移动端适配方案与实施记录

> 目标：让站点在手机/平板上保持新野兽派风格且功能完整可用。
> 原则：移动优先、拇指可达（主操作 ≥44px）、硬边硬阴影不变、不牺牲功能。

## 1. 断点体系

| 断点 | 场景 | 卡片列数 |
|---|---|---|
| <480px | 手机竖屏 | 1 列（首页入口 2 列） |
| 480–720px | 大屏手机/小平板 | 2 列 |
| 720–1024px | 平板 | 2–3 列 |
| >1024px | 桌面 | 现状（3–4 列） |

## 2. 导航（P0，已实施）

- **方案**：汉堡抽屉（推荐项）
- 桌面（>720px）：保留原顶栏 `topnav-desktop`
- 移动（≤720px）：顶栏只留 `品牌 + 汉堡按钮`；点开右侧滑出抽屉
- 抽屉内容：
  - 大号硬边菜单项（首页/作品库/排行榜/标签/上传 Demo/关于本站 + 管理后台）
  - 底部登录/注册 或 用户名/退出
- 路由切换自动关闭抽屉；点击遮罩关闭
- 样式：`.mobile-drawer` 全屏遮罩 + 右侧 320px 面板，硬阴影 + 黑边，菜单项按压感

## 3. 布局适配（P1，已实施）

- **顶栏**：≤720px 单行（品牌 + 汉堡），不再竖排
- **Tabs**（作品库/详情页/排行榜）：横向滚动（`overflow-x:auto`），不换行
- **表格**（管理后台）：`overflow-x:auto` 横向滑动（先横滑，后续可卡化）
- **视图栏/工具栏**：≤720px 纵向堆叠；模式轨道 `width:100%`
- **搜索框**：`max-width:100%`
- **评分面板**：≤720px 纵向堆叠（星星居中、元信息全宽）
- **首页入口**：≤480px 2 列（4 卡 2×2）
- **统计卡**：≤480px 2 列（`flex:1 1 45%`）
- **标签细条**：≤480px chips 横向滚动
- **Hero 标题**：≤480px 40px（已有）

## 4. 触控与细节（P2，已实施基础）

- ≤720px：`.btn` / `.tag-chip` 最小高度 40px
- 抽屉关闭按钮 36px、汉堡 44px
- 保留 `prefers-reduced-motion` 全局降级
- 后续可加：`@media (hover:hover)` 隔离 hover、`env(safe-area-inset-bottom)`（若用底部导航）
