# 论坛后端交接文字（给后端 agent）

> 前端按此契约开发；论坛为独立子站 `/forum`，与主站通过「Demo 讨论迁移 + 特殊链接解析」融合。
> 基础前缀 `/api/v1`，认证 HttpOnly Cookie `demo_token`，与主站一致。

## 一、数据模型

### Topic（主题）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| title | string | 标题（1~200） |
| content | text | Markdown 正文 |
| author_id | int? | 作者（匿名不允许发帖，必登录） |
| demo_slug | string? | 关联 Demo（可空；Demo 讨论自动主题用） |
| category | string | 分类（general / demo / 求助 / 分享 / 交流…，可配置） |
| tags | list | 复用主站 tag-keys（`key:value` / 对象） |
| pinned | bool | 置顶 |
| sticky | bool | 加精 |
| status | string | normal / hidden（隐藏） |
| reply_count | int | 回复数 |
| view_count | int | 浏览数 |
| created_at / updated_at | datetime | |

### Reply（回复）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 主键 |
| topic_id | int | 所属主题 |
| author_id | int | 作者（必登录） |
| content | text | Markdown |
| created_at | datetime | |

## 二、接口

### 公开
- `GET /forum/topics`：主题列表
  - query：`q`（搜索标题/正文）、`category`、`tag`（`k:v`，可重复）、`demo`（demo_slug）、`sort`（`newest|hot|reply`）、`page`、`page_size`
  - 返回：`{ items: TopicOut[], total, page, page_size }`
  - 排序：置顶/加精优先，再按 sort
  - `status=hidden` 不返回
- `GET /forum/topics/{id}`：主题详情（含正文；若 `demo_slug` 附带）
- `GET /forum/topics/{id}/replies`：回复列表（分页，时间正序）

### 登录
- `POST /forum/topics`：发帖
  - body：`{ title, content, category?, tags?, demo_slug? }`
  - 未登录 401
- `POST /forum/topics/{id}/replies`：回复
  - body：`{ content }`；未登录 401

### 管理（admin）
- `GET /forum/admin/topics`：全量列表（含 hidden，支持 status/category/pinned 筛选）
- `PUT /forum/admin/topics/{id}`：置顶/加精/分类/状态
- `DELETE /forum/admin/topics/{id}`：删除
- `DELETE /forum/admin/replies/{id}`：删除回复（可选）

## 三、Demo 评论迁移

- 一次性迁移脚本：把现有 `comments` 表按 `demo_id` 归集：
  - 为每个有评论的 demo 创建/复用 Topic（`demo_slug=demo.slug`，title=`讨论：{demo.title}`）
  - 每条 comment 转为 Reply（保留 author_id、content、created_at、父子关系拍平为楼层顺序）
- 迁移后 `comments` 接口可下线或只读；Demo 页「讨论」读论坛。

## 四、特殊链接解析所需

- `GET /forum/topics/{id}` 已覆盖（富卡片拿标题/作者/回复数）。
- Demo 详情 `GET /demos/{slug}` 已有（作品卡）。

## 五、主页入口（前端 only，后端无需支持）

- 主站首页右侧斜角入口卡 + 飞入动画 → `/forum`（前端实现）。

## 六、验收点

- 发帖/回复需登录；列表分页/搜索/分类/标签/置顶/加精/隐藏正确
- Demo 页「讨论」内嵌该 demo 主题；老评论迁移后可见
- 特殊链接 `/demo/xxx`、`/forum/topic/3` 在 Markdown 里渲染成卡片
