# 论坛整体设计（记录稿）

> 在「双轨制」（Demo 页轻量评论 + 论坛综合话题）之上，借鉴外部站点的完整论坛体验设计。

## 一、列表页：Reddit / V2EX 式主题卡

- **主题卡**：标题 + 作者 + 分类标签 + 回复/浏览 + 时间；置顶/加精印章
- **排序**：最新 / 热门 / 回复最多
  - 热度简化：`热度 = 回复数 + 浏览/50 + 时间衰减`
- **分类导航**：顶部横向分类（综合 / 求助 / 分享 / 作品讨论 / 公告），类似 GitHub Discussions category
- **筛选**：只看我参与的 / 只看精华（V2EX 节点思路）

## 二、详情页：Reddit 嵌套回复 + V2EX 楼层

- **主帖**：黄底标题条 + 作者信息 + 正文 Markdown + 相关 Demo 卡
- **回复**：
  - 默认**楼层模式**（#1 #2，V2EX 风格，轻量）
  - 可切换**嵌套模式**（Reddit 风格，回复可展开/折叠）
- **互动**：赞 / 感谢（GitHub reaction 简化）、引用回复（自动带原文）、`@用户名`
- **最佳答案**：求助帖可标记「已解决」（Stack Overflow 思路），列表显示绿色「已解决」徽标
- **作者徽标**：管理员 / 作者 / 老用户（HF role badge）

## 三、发帖：Product Hunt / GitHub 引导式

- **分类引导**：先选分类（综合/求助/分享/作品讨论），再填标题，正文可选
- **草稿自动保存**：localStorage 防手滑（GitHub issue 草稿）
- **关联 Demo**：发帖时可搜索关联作品，自动生成作品卡
- **预览**：已有 MarkdownEditor

## 四、用户 / 社区：Discord / HF 的「身份感」

- **用户主页聚合**：作品 + 发帖 + 回复 + 获赞数（HF profile）
- **轻量声望**：发帖/回复/被赞累计「声望」，显示在头像旁（V2EX 铜/银/金）
- **关注**：关注用户/主题，有新回复时站内通知（可先做「我参与的」列表代替推送）

## 五、移动端：底部快捷评论

- Demo 页/主题页在移动端底部固定一个输入条（Discord 式），点开即输入，不用滚到评论区

## 六、管理：GitHub 式 moderation

- 主题/回复可「关闭讨论」（不再接受新回复，保留内容）
- 举报队列已有；加「封禁用户」后其内容显示「已封禁用户」灰标
- 置顶/加精/隐藏/删除已有

## 七、首页 / 入口

- 论坛首页顶部放「热门话题」3~5 条（Reddit 首页思路）
- 主站首页斜角入口已有；可再加「最新讨论」小条（可选，不破坏纯粹性）

## 八、技术 / 性能

- 回复列表分页或「加载更多」（避免一次拉全部）
- 嵌套回复用 `parent_id` 字段（后端预留）
- 富卡片 / 搜索 / 分组标签全部复用现有组件

## 九、优先级建议

1. 双轨制（Demo 快捷评论 + 论坛分区）——解决当前痛点
2. 楼层/嵌套切换 + 赞/感谢 + 引用回复——互动感
3. 声望/关注/用户聚合——留人
4. 移动端底部输入条——体验
