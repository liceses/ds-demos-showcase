# 论坛融合设计（记录稿）

> 状态：前端设计讨论稿，供需求分析/后端同步。主站保持「纯粹作品展示」，论坛作为相对独立的子站，通过内容级关联打通。

## 一、定位与布局

- 论坛是**相对独立的子站**，挂在 `/forum` 下，有自己的顶栏（黑底黄字「讨论区」+ 板块/最新/热门/发帖 + 「← 回作品站」）。
- 主站顶栏/页脚在 `/forum` 路由隐藏（`meta.forum` 切换壳）。
- 论坛视觉共享新野兽派 token，但界面独立。

### 论坛视觉：牛皮纸背景
- 论坛页面背景使用**浅牛皮纸**（候选 `#f2e8d5`，需按可读性微调）：暖色、不刺眼。
- **卡片保持白纸** `--paper`：牛皮纸作画布、白卡作内容块，层次清晰、正文可读。
- 实现：论坛壳上覆写 `--paper-forum` 变量，**不改全局 `--paper`**（避免污染主站）；论坛页面背景用 `var(--paper-forum)`，卡片仍 `var(--paper)`。
- muted 文字改深棕灰（候选 `#6b5d43`）；黑色粗边框、硬阴影、黄/青/红点缀在牛皮纸上更出挑。

## 二、主站与论坛的关联点（主站零结构变化）

1. Demo 详情页操作区加一个小按钮「讨论 →」→ `/forum?demo=slug`
2. 标签详情页标题旁一行小字「相关讨论 n →」→ `/forum?tag=k:v`
3. 论坛顶栏常驻「← 回作品站」
4. 主站主页入口：**待定**（见「主页入口」一节）

主站首页不加卡片、不混排讨论、不改作品库/标签结构。

## 三、Demo 评论区 → 论坛（统一讨论）

- 每个 Demo 自动对应一个论坛主题（topic 增加 `demo_slug` 字段，可空）。
- `GET /forum/topic?demo=slug` 返回该 demo 的讨论主题；不存在时显示「发起讨论 →」（发帖自动带 demo_slug）。
- Demo 详情页「评论」Tab **改名为「讨论」**，内嵌该 demo 的论坛主题视图：
  - 顶部：主题标题 + 回复数 + 「去论坛」链接
  - 回复列表：复用论坛回复组件（Markdown 渲染）
  - 回复框：登录可回，未登录提示登录
- **历史评论一次性导入**：把现有 comments 表按 `demo_id` 归集，导入为对应主题的回复楼层（保留作者/时间）；迁移后 comments 接口可下线或只读。

## 四、特殊链接解析（内容级互链）

- `MarkdownRenderer` 增加内部链接富卡片：
  - `/demo/{slug}` → 调详情拿标题/封面，渲染「作品卡」（封面 + 标题 + 作者 + 跳转）
  - `/forum/topic/{id}` 或 `/forum?demo=...` → 调论坛详情拿标题，渲染「主题卡」（标题 + 作者 + 回复数 + 跳转）
- 实现：marked renderer 对内部链接先输出占位，组件 mounted 后扫描 `a[href]` 命中规则异步解析；**标题缓存 Map** 避免重复请求；失败降级普通链接。
- 论坛帖子、主站公告、Demo 描述均受益。

## 五、论坛页面骨架

- `/forum`：列表页（主题卡片：标题/作者/分类/标签/回复数/浏览数/时间；置顶/加精；分页/搜索/分类筛选）
- `/forum/topic/:id`：详情页（MarkdownRenderer 正文 + 回复列表 + 登录回复框）
- `/forum/new`：发帖页（标题 + 分类/标签 + Markdown 正文编辑/预览；未登录跳登录）
- 管理后台「论坛管理」Tab：先列表，后补操作

## 七、主页入口：斜角若隐若现卡（定稿）

- 主站首页**右侧边缘**固定一张**斜着露出一角**的入口卡（旋转约 -6°，只露约 60px 竖条，写「论坛 →」），平时若隐若现、不抢注意力。
- **hover**：向右滑出一点，露出标题「讨论区」+ 说明。
- **点击**：触发「接管动画」——入口卡从边缘**飞入铺满全屏**（牛皮纸面板 + 论坛 logo），约 500ms 后 `router.push('/forum')`。
- 离开论坛：论坛顶栏「← 回作品站」反向飞走（白面板滑出）。
- 实现：
  - 优先 **View Transitions API**（`document.startViewTransition(() => router.push('/forum'))` + CSS `::view-transition` 右侧滑入）；不支持时降级普通跳转。
  - 或纯 CSS 覆盖层：点击后 fixed 牛皮纸层从右滑入铺满，动画结束再跳转（兼容性最好）。
  - 移动端：斜角卡缩小为右下角小印章，避免占空间。
- 定位：`fixed right: -70px; top: 30%`；移动端底部小印章。
- 主站首页**不新增卡片**、不混排讨论内容。
