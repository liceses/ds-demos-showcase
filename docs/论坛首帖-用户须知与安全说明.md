# 论坛发帖须知 & 安全说明

欢迎来到「AI 全民制作人」讨论区 👋

这里是为了让大家围绕 AI Demo、模型、作品和创作过程交流的地方。为了让社区保持干净、安全、可长期讨论，我们设置了一些必要的规则和限制。**所有限制都是为了防刷帖、防恶意链接、防滥用，不是针对正常用户。**

---

## 1. 基本规则

- 请文明交流，尊重他人。
- 禁止广告、刷屏、引战、辱骂、人身攻击。
- 禁止发布违法、赌博、色情、诈骗、钓鱼类内容。
- 禁止批量注册小号刷帖。

违反规则的内容会被管理员删除或隐藏，严重者会被封禁账号。

---

## 2. 发帖 / 回复需要登录

- **游客可以浏览**论坛，但**发帖和回复必须登录**。
- 这是为了确认身份、减少机器人刷帖，也让管理员能处理违规内容。
- 后续可能会支持 GitHub 登录，绑定后视为更高信任用户；本地账号也可以正常使用。

---

## 3. 新用户发帖需要审核

- 新注册用户的前几条主题 / 回复会进入**管理员审核队列**。
- 审核通过后才会公开显示。
- 正常发言的用户很快会解除这个限制。
- 这不是针对你，而是防止新号一注册就刷垃圾内容。

---

## 4. 发帖 / 回复频率限制

为了防止刷屏，我们对发帖和回复设置了频率限制：

- 新用户：每小时发主题和回复的数量会有限制。
- 老用户：限制会放宽，但仍然存在。
- 如果短时间内操作过多，会提示“操作过于频繁，请稍后再试”。

这是常见论坛都有的防滥用机制。

---

## 5. 链接安全限制

帖子里的链接必须遵守以下规则：

- 只允许 `http://` 或 `https://` 链接。
- 禁止内网地址、本机地址、保留 IP 等危险链接。
- 禁止赌博、色情、诈骗、钓鱼等黑名单域名。
- 部分外链可能会先经过“安全跳转提示”，提醒你“即将离开本站”。

如果你发的链接被拦截，通常是链接格式或目标域名有问题，可以换一个正规链接再试。

---

## 6. 内容与 Markdown

- 论坛支持 **Markdown 排版**：标题、列表、代码块、表格、图片等。
- **禁止直接粘贴 HTML / 脚本**，所有内容都会经过安全过滤，防止 XSS 攻击。
- 请勿在正文里塞入大量无关代码或超大内容。

---

## 7. 举报与管理员

- 每条主题 / 回复都提供**举报**入口。
- 管理员可以：删除、隐藏、置顶、加精、封禁用户。
- 如果你看到违规内容，欢迎举报，我们会尽快处理。

---

## 8. 隐私说明

- 我们只保存发帖 / 回复所需的基本信息（作者、时间、内容）。
- 不会公开你的密码等敏感信息。
- 后续如果接入 GitHub 登录，只会用于身份认证和信任标记，不会公开你的 GitHub 隐私数据。

---

## 9. 为什么要有这些限制？

因为我们是一个**小站**，没有大规模审核团队，也没有强大风控系统。

所以我们选择用“登录 + 限流 + 审核 + 链接校验”这些低成本但有效的方式，保护这个社区不被垃圾内容淹没。

**你的正常讨论不会受到明显影响。** 如果遇到限制，通常等一会儿或完善内容后即可继续。

---
