## 一、项目定位与技术架构总览

**一句话定位**：`deepdemos.top`「AI 全民制作人（AI Demo Makers）」是一个 **AI 生成的网页 Demo 作品集展示站**，v2 将定位从「作品库」进一步升级为 **「从 Demo 观察模型能力的数据库」** —— 让每个 Demo 不再只是作品，而成为观察底层模型能力分布、同提示词横向对比、归属工作台的实证样本。

**架构拓扑**：

```
用户 ─ HTTPS → Cloudflare(边缘/CDN) → nginx(SPA 静态 + API 反代)
                                         │
              ┌──────────────────────────┼─────────────────────────┐
       主站 deepdemos.top      橱窗 astrademos.top(只读白名单)   沙箱 demo.deepdemos.top(preview/media)
              │                          │
        [前端] Vue 3.5 + TS + Vite 8 + Pinia 4 + vue-router4        (axios/marked/dompurify; src/astra 橱窗皮)
            axios 调用          │
              ▼                 ▼
        [后端] FastAPI + SQLAlchemy 2 + SQLite(WAL) + PyJWT + Pillow + oss2
            18 个 routers + services/*         预览沙箱静态托管
              ▼
        SQLite(WAL) · 本地文件存储(OSS_SERVE_LOCAL=true) · OSS(阿里云备份)
```

- **前端**：Vue 3.5 + TypeScript ~6.0 + Vite 8 + Pinia 4 + vue-router4；无 UI 框架，手写 neo-brutalist-playful 设计规范（`stylepkg/`）；零依赖 i18n；`hono` 与 `frontend/worker/`、`wrangler.toml` 为已弃用的 Cloudflare Worker 老方案（遗留未清理）。
- **后端**：FastAPI + SQLAlchemy2 + SQLite(WAL) + PyJWT + Pillow + oss2；uvicorn 单 worker（多 worker 不适合 SQLite）。
- **部署**：nginx 2 容器 + Cloudflare(HTTPS/CDN)；Docker Compose。生产走 `git pull && docker compose up --build`。
- **线上数据快照（t2，实时 GET）**：700 demos(web660/link21/zip19)、151 作者、569 用户、论坛 141 题、总 PV 100,273、今日 270、在线 72；top_models: ds-unknown 420/HY4 37/dsv4-pro 35；最新 demo 2026-09-02T16:25（站点活跃）。

## 五、下一步建议

### ✅ 上线前必须项（按实施顺序）

1. **立即 commit v2**（R1 —— 最高优先，先保住 96 项改动）。
2. **修复 H2 peek 越权**（R2）：补 approved + scope 检查 —— 高危泄露，改动小，优先于部署。
3. **修复 H1 zip 炸弹防护**（R3）：解压前 zipinfo 校验 ratio/entries/total_size —— 高危 DoS/扩盘，与 200MB 上限配套。
4. **补齐安全加固**（R4-R9）：安全响应头、容器非 root、强制改密与默认口令治理、/ready、确认 AUTO_APPROVE=false 与 JWT_SECRET 由 .env 覆盖。
5. **提交 + 推送 + 部署**：`git commit && git push &&`（服务器）`git pull && docker compose up --build`。
6. **线上执行 B5 迁移脚本** scripts/migrate_models_v2.py（幂等，须在真实数据上跑一次）。
7. **上线后验收**：核对 `/api/v1/models|tasks|explore|same-prompt` 由 404 → 200；demo 详情出现 models[]/tasks[]；`?rounds=` 过滤生效。
8. **校准文档**（R10/R12）：把 API_CONTRACT/USER_GUIDE/AI_AGENT_GUIDE 与「已上线实际」对齐，修正章节编号与 model 值数，清理 worker 遗留。

- M6/M7 契约与 sort 白名单对齐、M8 残留 N+1 收敛（L/M 级，非阻塞）。

## 结论概要

项目架构清晰、v2 **代码层质量高且基本完成**，但当前处于「**代码就绪、版本裸奔、线上 pre-v2**」的不稳定状态。唯一硬性红线是 **96 项未提交改动必须尽快 commit**；其次是 **H2 peek 越权与 H1 zip 炸弹两个高危**，应在部署前修复。修复并补齐安全加固后即可走「commit → push → pull → up --build → 迁移 → 验收」完成 v2 上线。
