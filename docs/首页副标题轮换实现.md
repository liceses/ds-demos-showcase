# 首页副标题轮换（打字机）实现文档

> 需求：把首页副标题从静态文案改为「轮换式」文案，风格参考 [01Virex/dsh-status-rotator](https://github.com/01Virex/dsh-status-rotator)（DSH 插件的状态行轮换），文案从该项目中文池精选。

## 效果

首页 hero 副标题不再是一句固定话，而是：

- 逐字打出当前文案（打字机效果）
- 停留约 2.6 秒
- 逐字删除
- 切换到下一条，循环往复
- 末尾带红色闪烁光标 `|`，mono 字体

## 涉及文件

| 文件 | 作用 |
|---|---|
| `frontend/src/views/HomeView.vue` | 文案池 + 打字机逻辑 + 模板 |
| `frontend/src/style.css` | `.tagline` / `.tagline-cursor` 样式 |

## 实现方法

### 1. 文案池

在 `HomeView.vue` 的 `<script setup>` 中维护一个字符串数组：

```ts
const taglinePhrases = [
  '正在收集 AI 生成的网页 Demo…',
  '正在整理会话日志与版本时间线…',
  // ... 精选自 dsh-status-rotator 中文池
]
```

> 注意：原项目文案池包含大量玩梗/擦边/攻击性内容，**上线前必须人工筛选**，只保留适合公开站点的条目。

### 2. 打字机状态

```ts
const tagline = ref('')
let taglineTimer: ReturnType<typeof setTimeout> | null = null
let taglineIdx = 0
let taglineChar = 0
let taglineDeleting = false
```

### 3. 核心 tick 函数

```ts
function tickTagline() {
  const phrase = taglinePhrases[taglineIdx]
  if (!taglineDeleting) {
    taglineChar++
    tagline.value = phrase.slice(0, taglineChar)
    if (taglineChar >= phrase.length) {
      taglineDeleting = true
      taglineTimer = setTimeout(tickTagline, 2600) // 打完后停留
      return
    }
  } else {
    taglineChar--
    tagline.value = phrase.slice(0, taglineChar)
    if (taglineChar <= 0) {
      taglineDeleting = false
      taglineIdx = (taglineIdx + 1) % taglinePhrases.length
    }
  }
  taglineTimer = setTimeout(tickTagline, taglineDeleting ? 18 : 42) // 删除快、打字慢
}
```

- 打字速度：42ms/字
- 删除速度：18ms/字
- 打完后停留：2600ms

### 4. 生命周期

```ts
onMounted(async () => {
  tickTagline()
  // ...原有数据加载
})

onBeforeUnmount(() => {
  if (taglineTimer) clearTimeout(taglineTimer)
})
```

> 必须清理定时器，否则 KeepAlive 缓存页面离开后仍会继续 tick（内存/性能问题）。

### 5. 模板

```html
<p class="sub">
  <span class="tagline">{{ tagline }}</span><span class="tagline-cursor">|</span>
  <a v-if="announcements.length" class="hero-ann-link" ...>查看公告 →</a>
</p>
```

### 6. 样式

```css
.tagline { font-family: var(--font-mono); }
.tagline-cursor {
  display: inline-block;
  margin-left: 2px;
  color: var(--red);
  font-weight: 900;
  animation: tagline-blink 0.9s steps(1) infinite;
}
@keyframes tagline-blink {
  0%, 100% { opacity: 1; }
  50% { opacity: 0; }
}
```

## 自定义

- **改文案**：直接编辑 `taglinePhrases` 数组
- **改速度**：调整 `tickTagline` 里的 `42 / 18 / 2600` 三个数字
- **改光标**：改 `.tagline-cursor` 颜色/动画

## 注意事项

- 与 KeepAlive 兼容：HomeView 被缓存时，`onBeforeUnmount` 不会触发（组件未销毁），但 `onMounted` 也只在首次进入触发一次；若需要「每次激活都从头开始」，可改用 `onActivated` 重启 tick。
- 文案池建议控制在 20~60 条，太多会让轮换显得冗长。
